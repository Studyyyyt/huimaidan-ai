# 惠买单小程序下单非支付接口对接文档

更新时间：2026-06-11

## 1. 对接范围

本文档对应第 2 批：到店买单创建流程与支付解耦。

本批只提供“创建待支付订单”能力，方便小程序先联调输入金额、优惠试算、订单确认和待支付展示。当前不接入第三方支付联调，不查询微信/支付宝支付渠道，不支持优惠券和积分抵扣进入订单。

说明：

- 当前不单独设计“取消订单”状态。
- 用户进入支付界面后未付款，不产生订单。
- 已支付订单发生退款时，后续按全额返还处理，微信支付退款联调用于支付售后批次。

## 2. 创建待支付订单

```text
POST /api/huimaidan/order/prepare
```

登录态：需要用户 Token。

### 2.1 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mer_id` | number | 是 | 商户 ID。 |
| `amount` | string/number | 是 | 用户输入消费金额，必须大于 0，最多两位小数。 |
| `mark` | string | 否 | 用户备注，最多 128 个字符。 |

示例：

```json
{
  "mer_id": 1001,
  "amount": "88.00",
  "mark": "用户备注"
}
```

### 2.2 响应字段

```json
{
  "group_order_id": 123,
  "order_id": 456,
  "order_sn": "202606110001H",
  "pay_price": "52.80",
  "discount": {
    "rule_id": 1,
    "rule_type": 1,
    "rule_type_label": "折扣",
    "title": "惠买单6折",
    "original_amount": "88.00",
    "pay_amount": "52.80",
    "saved_amount": "35.20"
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `group_order_id` | number | CRMEB 组合订单 ID，后续支付入口使用。 |
| `order_id` | number | 惠买单子订单 ID。 |
| `order_sn` | string | 订单号。 |
| `pay_price` | string | 当前实付金额，仅为订单待支付金额。 |
| `discount` | object | 真实优惠规则快照。 |

## 3. 显式不支持内容

`POST /api/huimaidan/order/prepare` 不接收商品、SKU、购物车、支付或真实抵扣字段。前端不要传以下字段：

- `product_id`
- `productId`
- `spu_id`
- `spuId`
- `sku`
- `sku_id`
- `skuId`
- `cart_id`
- `cartId`
- `cartIds`
- `cart_ids`
- `productAttr`
- `product_attr`
- `pay_type`
- `payType`
- `couponId`
- `coupon_id`
- `usePoints`
- `use_points`
- `pointsAmount`
- `points_amount`
- `discountType`
- `discount_type`

如果传入以上字段，接口会显式失败：

```json
{
  "message": "惠买单待支付订单不支持以下商品、购物车、支付或抵扣参数：pay_type"
}
```

## 4. 前端调用建议

```ts
export const huimaidanOrderApi = {
  prepare: (data: { mer_id: number; amount: string; mark?: string }) =>
    request.post('/huimaidan/order/prepare', data),
  detail: (orderId: number) =>
    request.get(`/huimaidan/order/detail/${orderId}`),
  payResult: (id: number) =>
    request.get(`/huimaidan/order/pay_result/${id}`),
}
```

## 5. 与原支付接口关系

| 接口 | 当前语义 |
| --- | --- |
| `POST /api/huimaidan/order/prepare` | 只创建惠买单待支付订单，不调用支付。 |
| `POST /api/huimaidan/order/create` | 保留原语义，创建订单后继续发起支付。 |
| `POST /api/huimaidan/order/pay/:id` | 现有支付入口，支付联调批次再对接。 |
| `GET /api/huimaidan/order/pay_result/:id` | 只读查询本地订单支付状态，不查第三方渠道。 |

## 6. 数据和部署说明

- 本批不新增 SQL。
- 继续复用 `eb_store_group_order`、`eb_store_order` 和惠买单一期扩展字段。
- 订单通过 `order_scene = 1` 标识为惠买单到店买单。
- 涉及 PHP 路由与长驻进程环境，部署后需要清理路由/应用缓存；如生产使用 Swoole，需要重启 Swoole。
