# 惠买单优惠抵扣与下单非支付接口对接完成文档

更新时间：2026-06-11

## 1. 对接概述

本次对接完成了惠买单小程序的优惠抵扣功能和下单非支付接口的前端集成。主要涉及以下内容：

- 新增 `createOrder` 接口，支持优惠券和积分抵扣
- 修改下单支付页面，根据用户选择自动调用不同接口
- 完善订单详情页，展示优惠抵扣明细

## 2. 涉及页面

### 2.1 下单支付页面
- **文件路径**：`src/pages/payment/checkout.vue`
- **功能**：
  - 用户输入金额后，自动获取可用优惠券列表
  - 用户可选择使用优惠券或积分抵扣
  - 根据是否使用优惠，自动调用不同接口：
    - 未使用优惠：调用 `prepareOrder` 接口
    - 使用优惠券或积分：调用 `createOrder` 接口

### 2.2 订单详情页面
- **文件路径**：`src/pages/orders/detail.vue`
- **功能**：
  - 展示订单基础信息
  - 展示优惠抵扣明细（优惠类型、优惠名称、优惠券抵扣金额、积分抵扣金额、平台承担金额）

## 3. API 接口对接

### 3.1 新增接口

#### createOrder - 创建订单并支付
- **接口地址**：`POST /api/huimaidan/order/create`
- **功能**：创建订单并模拟支付，支持优惠券和积分抵扣
- **请求参数**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mer_id` | number | 是 | 商户 ID |
| `amount` | string | 是 | 用户输入消费金额 |
| `pay_type` | string | 是 | 支付方式（routine/weixin/alipay等） |
| `couponId` | number | 否 | 用户券 ID |
| `usePoints` | boolean | 否 | 是否使用积分 |
| `mark` | string | 否 | 用户备注 |

### 3.2 已有接口

#### prepareOrder - 创建待支付订单
- **接口地址**：`POST /api/huimaidan/order/prepare`
- **功能**：只创建待支付订单，不支持优惠抵扣
- **使用场景**：用户未选择优惠券或积分时调用

#### getUserAssets - 获取用户资产
- **接口地址**：`GET /api/huimaidan/user/assets`
- **功能**：获取用户积分、佣金、优惠券数量等资产信息

#### getUsableCoupons - 获取可用优惠券
- **接口地址**：`GET /api/coupon/usable`
- **功能**：获取下单时可用的优惠券列表

## 4. 业务逻辑说明

### 4.1 下单流程

```
用户输入金额
    ↓
获取可用优惠券列表
    ↓
用户选择优惠券/积分
    ↓
判断是否有优惠
    ├─ 有优惠 → 调用 createOrder 接口
    └─ 无优惠 → 调用 prepareOrder 接口
    ↓
跳转到订单详情页
```

### 4.2 优惠抵扣规则

- 优惠券和积分抵扣固定由平台承担
- 折扣、优惠券、积分是否允许叠加由后台配置控制
- 使用积分时，必须已开启现有积分功能并配置积分抵扣比例
- 积分抵扣只传 `usePoints=true`，不传具体抵扣金额

### 4.3 不支持的参数

**createOrder 接口不支持以下参数**（前端不要传）：
- `pointsAmount`
- `points_amount`
- `discountType`
- `discount_type`

**prepareOrder 接口不支持以下参数**（前端不要传）：
- 商品、SKU、购物车相关参数
- 支付方式参数
- 优惠券、积分抵扣参数

## 5. 测试指南

### 5.1 测试环境准备

1. 确保后端已部署惠买单优惠抵扣相关接口
2. 确保后台已配置 `huimaidan_discount_stack_enabled`（惠买单优惠叠加策略）
3. 如启用积分抵扣，确认现有 `integral_status` 和 `integral_money` 已配置

5. **预期结果**：调用 `createOrder` 接口，订单详情页显示优惠券抵扣金额

2. 输入金额（如 100 元）

#### 测试用例 4：同时使用优惠券和积分

2. 输入金额（如 100 元）

4. 勾选"使用积分抵扣"
5. 点击"去支付"
6. **预期结果**：调用 `createOrder` 接口，订单详情页显示优惠券和积分抵扣金额

#### 测试用例 5：订单详情页展示

## 6. 部署说明

### 6.1 后端部署

1. 执行 `docs/sql/惠买单_小程序优惠抵扣配置.sql`
2. 后台保存 `huimaidan_discount_stack_enabled` 配置
3. 如启用积分抵扣，确认 `integral_status` 和 `integral_money` 已配置
4. 部署后清理系统配置缓存
5. 如使用 Swoole/队列等长驻进程环境，需要重启

### 6.2 前端部署

1. 代码已修改，无需额外配置
2. 运行 `pnpm build:mp` 构建微信小程序版本
3. 上传小程序代码并提交审核

## 7. 注意事项

1. **优惠券接口**：当前 `my-coupon.vue` 页面仍使用假数据，暂未对接用户优惠券列表接口
2. **积分计算**：积分抵扣金额由后端计算，前端只传 `usePoints=true`
3. **支付方式**：当前默认使用 `routine`（小程序支付），后续可根据需求扩展
4. **错误处理**：所有接口错误都会通过 `uni.showToast` 展示给用户
