# 惠买单小程序优惠抵扣接口对接文档

更新时间：2026-06-12

## 1. 对接范围

本文档对应第 4 批：优惠券和积分真实抵扣进入惠买单订单。

本批只在支付型下单接口中支持优惠券和积分真实抵扣：

```text
POST /api/huimaidan/order/create
```

`POST /api/huimaidan/order/prepare` 仍按非支付待支付订单口径处理，不接收 `couponId`、`usePoints`、`pointsAmount`、`discountType` 等抵扣字段，但接收 `useMemberDiscount` 用于试算是否参与会员折扣。

## 2. 业务规则

- 优惠券和积分抵扣固定由平台承担。
- 折扣、优惠券、积分是否允许叠加由后台配置 `huimaidan_discount_stack_enabled` 控制。
- 后台未配置叠加策略时，接口直接报错，不走默认策略。
- 使用积分时，必须已开启现有积分功能并配置积分抵扣比例 `integral_money`。
- `pointsAmount` 不支持前端指定，本批按 `usePoints=true` 自动使用可抵扣的最大积分，并保留最低 `0.01` 元实付。
- `useMemberDiscount=false` 表示不参与会员折扣；该状态下仍可使用优惠券和积分。
- 没有“取消订单”状态；支付后退款按后续售后批次全额返还，微信支付退款后置接入。

## 3. 优惠试算

```text
POST /api/huimaidan/discount/calculate
```

登录态：需要用户 Token。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mer_id` | number | 是 | 商户 ID。 |
| `amount` | string/number | 是 | 用户输入消费金额，必须大于 0，最多两位小数。 |
| `useMemberDiscount` | boolean/string/number | 否 | 是否参与会员折扣。默认 `true`；传 `false`、`0`、`"0"` 表示不参与会员折扣。 |

说明：试算接口只计算商户/会员折扣口径，不核销优惠券、不扣积分。前端如要展示券和积分，需要继续调用可用券接口并在最终 `order/create` 传 `couponId`、`usePoints`。

## 4. 下单并发起支付

```text
POST /api/huimaidan/order/create
```

登录态：需要用户 Token。

### 3.1 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mer_id` | number | 是 | 商户 ID。 |
| `amount` | string/number | 是 | 用户输入消费金额，必须大于 0，最多两位小数。 |
| `pay_type` | string | 是 | 支付方式，沿用现有值：`balance`、`weixin`、`routine`、`h5`、`alipay`、`alipayQr`、`weixinQr`。 |
| `couponId` | number | 否 | 用户券 ID，对应 `GET /api/coupon/usable` 返回的 `id`。 |
| `usePoints` | boolean/string/number | 否 | 是否使用积分。支持 `true`、`1`、`"1"`。 |
| `useMemberDiscount` | boolean/string/number | 否 | 是否参与会员折扣。默认 `true`；传 `false`、`0`、`"0"` 表示不参与会员折扣。 |
| `mark` | string | 否 | 用户备注，最多 128 个字符。 |
| `return_url` | string | 否 | 支付渠道需要时传入。 |

示例：

```json
{
  "mer_id": 1001,
  "amount": "88.00",
  "pay_type": "routine",
  "couponId": 101,
  "usePoints": true,
  "useMemberDiscount": false,
  "mark": "用户备注"
}
```

### 4.2 不支持参数

前端不要传以下字段：

- `pointsAmount`
- `points_amount`
- `discountType`
- `discount_type`

如果传入，接口会显式失败：

```json
{
  "message": "惠买单订单暂未支持以下抵扣参数：pointsAmount"
}
```

## 5. 响应字段

该接口保持原支付接口响应结构，返回内容随支付方式变化。订单本地快照中会记录抵扣拆分字段，前端查询订单详情或支付结果时以 `discount` 对象展示可公开字段。

`discount` 示例：

```json
{
  "rule_id": 1,
  "rule_type": 1,
  "rule_type_label": "折扣",
  "title": "惠买单6折",
  "original_amount": "100.00",
  "pay_amount": "65.00",
  "saved_amount": "35.00",
  "member_discount_enabled": false,
  "coupon_user_id": 101,
  "coupon_id": 88,
  "coupon_deduction_amount": "10.00",
  "integral": 500,
  "integral_deduction_amount": "5.00",
  "platform_bear_coupon_amount": "10.00",
  "platform_bear_integral_amount": "5.00"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `pay_amount` | string | 最终实付金额。 |
| `saved_amount` | string | 总优惠金额，包含折扣、优惠券、积分抵扣。 |
| `member_discount_enabled` | boolean | 是否参与会员折扣。 |
| `coupon_user_id` | number | 使用的用户券 ID，未使用为 `0`。 |
| `coupon_id` | number | 优惠券模板 ID，未使用为 `0`。 |
| `coupon_deduction_amount` | string | 本单优惠券抵扣金额。 |
| `integral` | number | 本单使用积分数量。 |
| `integral_deduction_amount` | string | 本单积分抵扣金额。 |
| `platform_bear_coupon_amount` | string | 平台承担的优惠券金额。 |
| `platform_bear_integral_amount` | string | 平台承担的积分抵扣金额。 |

## 6. 常见错误

| 场景 | 错误文案 |
| --- | --- |
| 未配置惠买单叠加策略 | `请先配置惠买单优惠叠加策略` |
| 配置为不叠加但同时存在多种优惠 | `当前配置不支持优惠叠加` |
| 优惠券不属于用户、不可用、未到门槛或不适用商户 | `优惠券不可用` |
| 使用积分但积分功能未开启 | `积分抵扣未开启` |
| 使用积分但抵扣比例未配置 | `请先配置积分抵扣比例` |
| 用户积分不足 | `积分不足` |
| 传入 `pointsAmount`、`discountType` | `惠买单订单暂未支持以下抵扣参数：...` |

## 7. 前端调用建议

```ts
export const huimaidanOrderApi = {
  create: (data: {
    mer_id: number
    amount: string
    pay_type: string
    couponId?: number
    usePoints?: boolean
    useMemberDiscount?: boolean
    mark?: string
    return_url?: string
  }) => request.post('/huimaidan/order/create', data),
  calculate: (data: { mer_id: number; amount: string; useMemberDiscount?: boolean }) =>
    request.post('/huimaidan/discount/calculate', data),
  usableCoupons: (params: { mer_id: number; amount: string; page?: number; limit?: number }) =>
    request.get('/coupon/usable', params),
}
```

前端选券时使用 `GET /api/coupon/usable` 返回的 `id` 作为 `couponId`。积分抵扣只传 `usePoints=true`，不传具体抵扣金额。“不参与优惠”页签按当前确认口径应理解为“不参与会员折扣”，因此需要传 `useMemberDiscount=false`，但仍可继续传 `couponId`、`usePoints`。

## 8. 部署说明

- 执行 `docs/sql/惠买单_小程序优惠抵扣配置.sql`。
- 后台保存 `huimaidan_discount_stack_enabled`，否则下单会报错。
- 如启用积分抵扣，确认现有 `integral_status` 和 `integral_money` 已配置。
- 部署后清理系统配置缓存；Swoole/队列等长驻进程环境需要重启。
