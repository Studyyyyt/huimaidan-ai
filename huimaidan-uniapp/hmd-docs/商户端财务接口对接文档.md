# 商户端财务信息接口对接文档

## 概述

本文档描述小程序商户端财务模块的API接口，包括财务概览统计、销售额度信息和余额明细列表三个接口。

## 认证方式

**商户端统一使用 `X-Token` 请求头进行认证**（与商户登录接口一致）。

```
X-Token: {merchant_token}
```

> **注意：** 商户Token和用户Token是**独立的两套系统**。
>
> - 商户端接口使用 `X-Token` + `MerchantTokenMiddleware` 认证
> - 用户端接口使用 `X-Token` / `Authorization` + `UserTokenMiddleware` 认证
>
> 两者Token不能混用，商户登录获取的Token只能用于商户端接口。

**Token获取方式：** 通过商户登录接口 `POST /api/mer/login` 获取

## 接口列表

### 1. 财务概览统计

**接口地址：** `GET /api/mer/huimaidan/finance/overview`

**功能说明：** 获取商户财务概览统计数据，包括累计收款、昨日/本月新增收款、累计退款、昨日/本月新增退款。

**请求头：**
```
Content-Type: application/json
X-Token: {token}
```

**请求参数：** 无

**响应示例：**
```json
{
    "code": 200,
    "msg": "success",
    "data": {
        "totalReceived": 1080.00,
        "yesterdayReceived": 0.00,
        "monthReceived": 0.00,
        "totalRefund": 400.00,
        "yesterdayRefund": 0.00,
        "monthRefund": 0.00
    }
}
```

**字段说明：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| totalReceived | number | 累计收款金额 |
| yesterdayReceived | number | 昨日新增收款金额 |
| monthReceived | number | 本月新增收款金额 |
| totalRefund | number | 累计退款金额 |
| yesterdayRefund | number | 昨日新增退款金额 |
| monthRefund | number | 本月新增退款金额 |

---

### 2. 销售额度信息

**接口地址：** `GET /api/mer/huimaidan/finance/quota`

**功能说明：** 获取商户已销售额度和总额度信息。

**请求头：**
```
Content-Type: application/json
X-Token: {token}
```

**请求参数：** 无

**响应示例：**
```json
{
    "code": 200,
    "msg": "success",
    "data": {
        "salesQuota": 974.00,
        "totalQuota": 0
    }
}
```

**字段说明：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| salesQuota | number | 已销售额度（累计收款金额） |
| totalQuota | number | 总额度（0表示无限制） |

**注意：**
- `salesQuota` 从财务记录中实时计算，等于商户累计订单收入金额
- `totalQuota` 目前返回0表示无限制，如需启用总额度限制，需在 `merchant` 表添加 `huimaidan_total_quota` 字段

---

### 3. 余额明细列表

**接口地址：** `GET /api/mer/huimaidan/finance/records`

**功能说明：** 获取商户余额明细流水记录列表，支持分页和筛选。

**请求头：**
```
Content-Type: application/json
X-Token: {token}
```

**请求参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | int | 否 | 1 | 页码 |
| limit | int | 否 | 10 | 每页数量 |
| type | string | 否 | - | 筛选类型：income=收入，expense=支出，不传则全部 |
| date | string | 否 | - | 日期筛选，格式：Y-m-d |
| keyword | string | 否 | - | 关键词搜索（订单号、流水号） |

**响应示例：**
```json
{
    "code": 200,
    "msg": "success",
    "data": {
        "list": [
            {
                "id": 1001,
                "type": "income",
                "amount": 150.00,
                "balance": 0,
                "mark": "订单收入",
                "create_time": "2024-01-01 10:00:00"
            },
            {
                "id": 1002,
                "type": "expense",
                "amount": 50.00,
                "balance": 0,
                "mark": "退款支出",
                "create_time": "2024-01-01 11:00:00"
            }
        ],
        "count": 50
    }
}
```

**字段说明：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int | 记录ID |
| type | string | 类型：income=收入，expense=支出 |
| amount | number | 交易金额（正数） |
| balance | number | 交易后余额（暂未实现，返回0） |
| mark | string | 交易说明/备注 |
| create_time | string | 交易时间 |

### 4. 提现记录列表

**接口地址：** `GET /api/mer/huimaidan/settlement/withdraw/list`

**功能说明：** 获取商户提现记录列表，支持分页和筛选。

**请求头：**
```
Content-Type: application/json
X-Token: {token}
```

**请求参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | int | 否 | 1 | 页码 |
| limit | int | 否 | 10 | 每页数量 |
| date | string | 否 | - | 日期筛选，格式：Y-m-d |
| status | int | 否 | - | 状态筛选：0=处理中, 1=成功, 2=失败 |
| account_type | int | 否 | - | 提现方式筛选：2=微信, 3=支付宝 |

**响应示例：**
```json
{
    "code": 200,
    "msg": "success",
    "data": {
        "list": [
            {
                "id": 1001,
                "amount": 10.00,
                "balance": 20.00,
                "financial_type": 2,
                "financial_type_text": "微信",
                "card_last_four": "",
                "status": 1,
                "status_text": "成功",
                "mark": "提现到微信",
                "create_time": "2026-06-01 12:30:00"
            }
        ],
        "count": 10
    }
}
```

**字段说明：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int | 提现记录ID（financial_id） |
| amount | number | 提现金额（extract_money） |
| balance | number | 提现后余额（mer_money，申请时的余额快照） |
| financial_type | int | 提现方式：1=银行卡, 2=微信, 3=支付宝 |
| financial_type_text | string | 提现方式文本 |
| card_last_four | string | 银行卡后四位（仅银行卡提现时返回） |
| status | int | 状态：0=处理中, 1=成功, 2=失败 |
| status_text | string | 状态文本 |
| mark | string | 商户备注 |
| create_time | string | 创建时间 |

**状态映射说明：**

| 数据库 status | 数据库 financial_status | 接口返回 status | 说明 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 待审核（处理中） |
| 1 | 0 | 0 | 审核通过待打款（处理中） |
| 1 | 1 | 1 | 已打款（成功） |
| -1 | 0 | 2 | 审核拒绝（失败） |

## 注意事项

1. **认证方式**：所有接口都需要在请求头中携带有效的商户Token
2. **权限控制**：接口已配置商户认证中间件，未登录或Token过期将返回401错误
3. **数据范围**：商户只能查看自己店铺的财务数据，不能查看其他商户数据
4. **金额精度**：所有金额字段保留2位小数
5. **时区**：所有时间均为服务器本地时间（中国标准时间）

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录或Token过期 |
| 403 | 无权限访问 |
| 500 | 服务器内部错误 |

- `MerchantRepository` - 商户仓库，提供商户信息查询

### 路由配置

```php
// 财务接口
Route::group('huimaidan/finance', function () {
    Route::get('overview', 'Finance/overview')->name('merchantHuimaidanFinanceOverview')->option(['_alias' => '财务概览统计']);
    Route::get('quota', 'Finance/quota')->name('merchantHuimaidanFinanceQuota')->option(['_alias' => '销售额度信息']);
    Route::get('records', 'Finance/records')->name('merchantHuimaidanFinanceRecords')->option(['_alias' => '余额明细列表']);
})->prefix('merchant.huimaidan.')->option([
    '_path' => '/huimaidan/finance',
    '_auth' => true,
]);

// 提现记录列表（在 huimaidan/settlement 分组下新增）
Route::get('withdraw/list', 'Withdraw/list')->name('merchantHuimaidanWithdrawList')->option(['_alias' => '提现记录列表']);
```
