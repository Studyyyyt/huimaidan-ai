# 惠买单商户端小程序对接文档

## 一、项目概述

本文档描述CRMEB多商户系统（MER v3.4）的商户端接口，支持商户端小程序登录、经营数据查看、订单管理、财务展示等功能。

### 1.1 技术栈
- 框架：ThinkPHP 6.x
- 认证方式：JWT Token
- 数据格式：JSON

### 1.2 URL前缀
- 商户端API前缀：`mer/`
- 用户端API前缀：`api/`

## 二、商户端登录流程

### 2.1 登录时序图

```
商户小程序 → 后端API
    │
    ├─── 1. 检查是否需要滑块验证码 ──→ POST /mer/ajstatus
    │         返回: { status: true/false }
    │
    ├─── 2. 获取验证码(如需) ──→ GET /mer/captcha
    │         返回: { key, captcha }
    │
    ├─── 3. 滑块验证码验证(如需) ──→ GET /mer/ajcaptcha
    │         POST /mer/ajcheck
    │
    └─── 4. 账号密码登录 ──→ POST /mer/login
              返回: { token, exp, admin }
```

### 2.2 登录接口详情

#### 2.2.1 检查滑块验证码状态
```
POST /mer/ajstatus

请求参数:
{
    "account": "商户账号"
}

响应:
{
    "code": 200,
    "data": {
        "status": true  // true=需要滑块验证, false=不需要
    }
}
```

#### 2.2.2 获取图形验证码
```
GET /mer/captcha

响应:
{
    "code": 200,
    "data": {
        "key": "验证码key",
        "captcha": "base64图片"
    }
}
```

#### 2.2.3 获取滑块验证码
```
GET /mer/ajcaptcha?captchaType=clickWord

响应:
{
    "code": 200,
    "data": {
        "bigImage": "大图base64",
        "smallImage": "小图base64",
        "token": "验证token"
    }
}
```

#### 2.2.4 验证滑块验证码
```
POST /mer/ajcheck

请求参数:
{
    "token": "验证token",
    "pointJson": "坐标JSON",
    "captchaType": "clickWord"
}
```

#### 2.2.5 商户登录（核心接口）
```
POST /mer/login

请求参数:
{
    "account": "商户账号",          // 格式: "merId@adminAccount" 或 "adminAccount"
    "password": "密码",
    "code": "验证码key(可选)",
    "key": "验证码(可选)",
    "captchaType": "滑块类型(可选)",
    "captchaVerification": "滑块验证结果(可选)"
}

响应成功:
{
    "code": 200,
    "data": {
        "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
        "exp": 1687123456,        // token过期时间戳
        "admin": {
            "merchant_admin_id": 1,
            "mer_id": 100,
            "account": "admin",
            "real_name": "管理员",
            "phone": "13800138000",
            "status": 1,
            "level": 0,
            "roles": "1,2"
        }
    }
}

响应失败:
{
    "code": 100,
    "message": "账号或密码错误"
}
```

**账号格式说明：**
- 顶级管理员：直接输入账号名，如 `admin`
- 商户管理员：格式为 `商户ID@账号名`，如 `100@manager`

### 2.3 Token管理

#### 2.3.1 Token使用方式
在请求头中传递：
```
X-Token: eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
```

#### 2.3.2 Token有效期配置（config/admin.php）
```php
'token_exp' => 6,              // Token有效期：6小时
'token_valid_exp' => 30,       // 自动续期窗口：30分钟
'captcha_exp' => 30,           // 验证码有效期：30分钟
```

#### 2.3.3 Token过期处理
- 当Token过期但仍在续期窗口内（30分钟），系统会自动续期
- 超过续期窗口，需要重新登录

#### 2.3.4 退出登录
```
GET /mer/logout

Headers:
X-Token: <token>

响应:
{
    "code": 200,
    "data": "退出登录"
}
```

## 三、中间件说明

商户端API请求需经过以下中间件链：

```
AllowOriginMiddleware → MerchantTokenMiddleware → MerchantAuthMiddleware → MerchantCheckBaseInfoMiddleware → LogMiddleware
```

| 中间件 | 功能 |
|--------|------|
| AllowOriginMiddleware | 跨域处理 |
| MerchantTokenMiddleware | JWT Token验证 |
| MerchantAuthMiddleware | 权限验证（菜单权限） |
| MerchantCheckBaseInfoMiddleware | 商户基本信息完整性检查 |
| LogMiddleware | 操作日志记录 |

## 四、用户端（小程序）登录流程

### 4.1 小程序授权登录
```
POST /api/auth

请求参数:
{
    "code": "wx.login获取的code",
    "iv": "加密算法的初始向量",
    "encryptedData": "加密后的用户信息",
    "spread": "推荐人ID(可选)"

响应成功:
{
    "code": 200,
    "data": {
        "token": "用户token",
        "exp": 过期时间戳,
        "userInfo": { ... }
    }
}
```

### 4.2 小程序手机号绑定
```

请求参数:
{
    "code": "wx.login获取的code",
    "phone_code": "手机号获取code",
    "auth_token": "授权token(可选)"
}

响应:
{
    "code": 200,
    "data": {
        "token": "用户token",
        "exp": 过期时间戳
    }
}
```

### 4.3 Token续期
```
POST /api/auth/refresh_token

Headers:
Authorization: Bearer <user_token>

响应:
{
    "code": 200,
    "data": {
        "token": "新token",
        "exp": 新过期时间戳
    }
}
```

## 八、错误码说明

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 100 | 业务错误（请查看message） |
| 401 | 未登录或Token无效 |
| 403 | 无权限访问 |
| 404 | 接口不存在 |
| 500 | 服务器错误 |

### 常见错误信息
- `请登录` - Token缺失或无效
- `token已过期，请重新登录` - Token过期且超出续期窗口
- `无效的token` - Token来源不是商户端
- `账号不存在` - 账号不正确
- `账号已关闭` - 账号被禁用
- `商户已被锁定` - 商户账号被冻结
- `没有权限访问` - 无对应菜单权限

## 九、注意事项

### 9.1 Token安全
- Token有效期为6小时
- 在续期窗口（30分钟）内访问任意接口会自动续期
- 建议在客户端保存token，每次请求携带在X-Token头中

### 9.2 登录失败处理
- 连续登录失败超过3次需要滑块验证
- 滑块验证有效期5分钟
- 登录失败缓存15分钟自动清除

### 9.3 接口调用规范
- 所有请求需要携带X-Token头（登录接口除外）
- GET请求参数通过query string传递
- POST请求参数通过JSON body传递
- 响应格式统一为JSON

### 9.4 商户ID说明
- `mer_id` 是商户唯一标识
- 商户管理员账号格式为 `mer_id@账号名`
- 通过Token解析可获取当前登录商户的mer_id

## 十、附录

### 10.1 请求示例

#### 商户登录示例
```javascript
const response = await fetch('/mer/login', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        account: '100@manager',
        password: '123456'
    })
});
const data = await response.json();
if (data.code === 200) {
    const { token, admin } = data.data;
    localStorage.setItem('mer_token', token);
}
```

#### 商户端请求示例
```javascript
const token = localStorage.getItem('mer_token');
const response = await fetch('/mer/info', {
    method: 'GET',
    headers: {
        'X-Token': token
    }
});
const data = await response.json();
```

### 10.2 小程序登录示例
```javascript
// 1. 获取code
const { code } = await wx.login();

// 2. 授权登录
const response = await fetch('/api/auth', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        code: code,
        iv: iv,
        encryptedData: encryptedData
    })
});
const data = await response.json();
if (data.code === 200) {
    const { token } = data.data;
    wx.setStorageSync('user_token', token);
}
```
