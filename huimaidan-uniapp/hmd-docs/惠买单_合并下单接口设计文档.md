# 惠买单合并下单接口 - 前端对接说明

更新时间：2026-06-12

## 1. 需求背景

当前下单支付页面有两个标签："优惠价格"和"不参与会员折扣"，需要合并为一个页面，同时显示两个输入框：
- **优惠金额**：支持会员折扣、优惠券、积分
- **不参与优惠金额**：不使用任何优惠（会员折扣、优惠券、积分都不使用）

最终支付金额 = 优惠金额 + 不参与优惠金额

## 2. 接口地址

```
POST /api/huimaidan/order/createCombined
```

## 3. 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `mer_id` | number | ✅ | 商户ID |
| `discount_amount` | string | ✅ | 优惠金额（支持会员折扣、优惠券、积分），至少一个金额>0 |
| `no_discount_amount` | string | ✅ | 不参与优惠金额（不使用任何优惠），至少一个金额>0 |
| `pay_type` | string | ✅ | 支付方式：balance/weixin/routine/h5/alipay/alipayQr/weixinQr |
| `couponId` | number | ❌ | 优惠券ID（只针对优惠金额部分） |
| `usePoints` | boolean | ❌ | 是否使用积分（只针对优惠金额部分） |
| `useMemberDiscount` | boolean | ❌ | 是否使用会员折扣（默认true，只针对优惠金额部分） |
| `mark` | string | ❌ | 备注（最多128字） |

## 4. 请求示例

```json
{
  "mer_id": 123,
  "discount_amount": "80.00",
  "no_discount_amount": "20.00",
  "pay_type": "routine",
  "couponId": 456,
  "usePoints": true,
  "useMemberDiscount": true,
  "mark": "请安排靠窗位置"
}
```

## 5. 响应结果

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | number | 状态码，200成功 |
| `msg` | string | 提示信息 |
| `data` | object | 支付参数（用于调起支付） |

### data 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `order_id` | number | 订单ID |
| `type` | string | 支付类型（weixin/alipay/balance等） |
| 其他 | - | 不同支付方式返回不同参数（微信/支付宝SDK所需参数） |

## 6. 错误码

| 错误码 | 错误信息 | 说明 |
|--------|----------|------|
| 400 | 参数错误 | 缺少必填参数或参数格式错误 |
| 400 | 金额无效 | discount_amount 和 no_discount_amount 不能同时为空或<=0 |
| 400 | 优惠券不可用 | 优惠券不适用当前商户或金额不足 |
| 400 | 积分不足 | 用户积分不足以抵扣 |
| 400 | 请先配置惠买单优惠叠加策略 | 后台未配置优惠叠加策略 |
| 400 | 请选择正确的支付方式 | pay_type 不在支持范围内 |
| 500 | 服务器错误 | 服务器内部错误 |

## 7. 前端调用示例

### TypeScript 接口定义

### Vue3 + UniApp 调用示例

```typescript
// 调用示例
const params: IOrderCreateCombinedParams = {
  mer_id: shopId.value,
  discount_amount: discountFormData.value.amount || '0',
  no_discount_amount: noDiscountFormData.value.amount || '0',
  pay_type: 'routine',
  couponId: selectedCouponId.value || undefined,

const res = await createCombinedOrder(params)

// 处理支付回调
if (res.type === 'weixin') {

    provider: 'wxpay',
    orderInfo: res,
    success: () => {
      uni.showToast({ title: '支付成功' })
    },
    fail: (err) => {
      uni.showToast({ title: '支付取消' })

  })

  // 调起支付宝
  // #ifdef MP-ALIPAY
  my.tradePay({
    tradeNO: res.tradeNO,
    success: () => {
      uni.showToast({ title: '支付成功' })
    },
    fail: (err) => {
      uni.showToast({ title: '支付取消' })
    },
  })
  // #endif
} else if (res.type === 'balance') {
  // 余额支付成功
  uni.showToast({ title: '支付成功' })
}
```

## 8. 业务逻辑说明

### 8.1 优惠金额部分

1. **会员折扣**：如果 `useMemberDiscount=true`，计算会员折扣
2. **优惠券抵扣**：如果提供了 `couponId`，验证并使用优惠券
3. **积分抵扣**：如果 `usePoints=true`，计算积分抵扣

### 8.2 不参与优惠金额部分

1. 不计算会员折扣
2. 不使用优惠券
3. 不使用积分
4. 直接计入最终支付金额

### 8.3 最终支付金额计算

```
最终支付金额 = 优惠金额 - 会员折扣 - 优惠券抵扣 - 积分抵扣 + 不参与优惠金额
```

## 9. 注意事项

1. **金额格式**：`discount_amount` 和 `no_discount_amount` 都是字符串类型，最多两位小数
2. **至少一个>0**：两个金额不能同时为0或空
3. **优惠范围**：优惠券、积分、会员折扣都只针对 `discount_amount` 部分
4. **商户成本**：`no_discount_amount` 部分平台不抽成，商户全额收到

## 10. 测试用例

### 测试用例 1：只输入优惠金额
- discount_amount: "100"
- no_discount_amount: "0"
- 预期：只计算优惠金额部分的折扣

- discount_amount: "0"
- no_discount_amount: "100"
- 预期：不计算任何折扣，最终支付100元

### 测试用例 3：同时输入两个金额
- discount_amount: "80"
- no_discount_amount: "20"
- 预期：优惠金额80元计算折扣，不参与优惠金额20元不计算折扣

### 测试用例 4：优惠金额使用优惠券和积分
- discount_amount: "100"
- no_discount_amount: "0"
- couponId: 123
- usePoints: true
- 预期：优惠券和积分都只针对100元优惠金额计算
