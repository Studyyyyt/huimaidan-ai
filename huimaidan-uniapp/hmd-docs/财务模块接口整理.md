# 商户端财务模块 - 接口整理

## 一、已接入的接口 ✅

### 1. 财务概览统计
- **接口地址：** `GET /mer/huimaidan/finance/overview`
- **接口文档：** ✅ 有（商户端财务接口对接文档.md）
- **前端代码：** ✅ 已接入
- **响应字段：**
  - `totalReceived` - 累计收款金额
  - `yesterdayReceived` - 昨日新增收款金额
  - `monthReceived` - 本月新增收款金额
  - `totalRefund` - 累计退款金额
  - `yesterdayRefund` - 昨日新增退款金额
  - `monthRefund` - 本月新增退款金额

### 2. 销售额度信息
- **接口地址：** `GET /mer/huimaidan/finance/quota`
- **接口文档：** ✅ 有（商户端财务接口对接文档.md）
- **前端代码：** ✅ 已接入
- **响应字段：**
  - `salesQuota` - 已销售额度（累计收款金额）
  - `totalQuota` - 总额度（0表示无限制）

### 3. 余额明细列表
- **接口地址：** `GET /mer/huimaidan/finance/records`
- **接口文档：** ✅ 有（商户端财务接口对接文档.md）
- **前端代码：** ✅ 已接入
- **请求参数：**
  - `page` - 页码（默认1）
  - `limit` - 每页数量（默认10）
  - `type` - 筛选类型：income=收入，expense=支出
  - `date` - 日期筛选，格式：Y-m-d
  - `keyword` - 关键词搜索（订单号、流水号）
- **响应字段：**
  - `list[].id` - 记录ID
  - `list[].type` - 类型：income=收入，expense=支出
  - `list[].amount` - 交易金额（正数）
  - `list[].balance` - 交易后余额（暂未实现，返回0）
  - `list[].mark` - 交易说明/备注
  - `list[].create_time` - 交易时间
  - `count` - 总数量

### 4. 提现概览
- **接口地址：** `GET /mer/huimaidan/settlement/overview`
- **接口文档：** ✅ 有（商户端对接文档.md）
- **前端代码：** ✅ 已接入
- **响应字段：**
  - `available_balance` - 可提现余额
  - `pending_amount` - 提现中金额
  - `total_withdraw` - 累计提现

### 5. 提现申请
- **接口地址：** `POST /mer/huimaidan/settlement/withdraw/apply`
- **接口文档：** ✅ 有（商户端对接文档.md）
- **前端代码：** ✅ 已接入
- **请求参数：**
  - `extract_money` - 提现金额
  - `financial_type` - 提现方式：1=银行卡, 2=微信, 3=支付宝
  - `mark` - 提现备注
