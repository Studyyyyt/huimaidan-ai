## 4. 新增 API 接口

### 4.1 类型定义

```typescript
// 创建待支付订单请求参数
export interface IOrderPrepareParams {
  mer_id: number
  amount: string
  mark?: string
}

// 优惠规则快照
export interface IDiscountSnapshot {
  rule_id: number
  rule_type: number
  rule_type_label: string
  title: string
  original_amount: string
  pay_amount: string
  saved_amount: string
}

// 创建待支付订单响应
export interface IOrderPrepareResult {
  group_order_id: number
  order_id: number
  order_sn: string
  pay_price: string
  discount: IDiscountSnapshot
}

// 用户资产聚合
export interface IUserAssets {
  commission: string
  points: number
  couponCount: number
  vipLevel: number
}

// 订单详情
export interface IOrderDetail {
  order_id: number
  order_sn: string
  mer_id: number
  mer_name: string
  amount: string
  pay_price: string
  discount_amount: string
  status: number
  status_text: string
  pay_time: string
  create_time: string
  mark: string
  discount: IDiscountSnapshot
}
```

### 4.2 API 函数

```typescript
// 创建待支付订单
export function prepareOrder(params: IOrderPrepareParams) {
  return http.post<IOrderPrepareResult>('/api/huimaidan/order/prepare', params)
}

// 获取订单详情
export function getOrderDetail(orderId: number) {
  return http.get<IOrderDetail>(`/api/huimaidan/order/detail/${orderId}`)
}

// 获取用户资产聚合
export function getUserAssets() {
  return http.get<IUserAssets>('/api/huimaidan/user/assets')
}
```

## 6. 测试指南

### 6.1 测试前提

1. 后端已部署第二、三批接口
2. 已登录有效的用户账号
3. 已有有效的商户数据（mer_id）

### 6.2 测试用例

#### 测试用例 1：创建待支付订单

**前置条件：**
- 用户已登录
- 已进入商户详情页
- 点击"优惠买单"进入支付页面

**操作步骤：**
1. 进入支付页面 `pages/payment/checkout`
2. 输入消费金额（如：100）
3. 可选：输入备注信息
4. 点击"去支付"按钮

**预期结果：**
- 调用 `POST /api/huimaidan/order/prepare` 接口
- 返回订单信息（order_id, order_sn, pay_price, discount）
- 显示"订单创建成功"提示
- 跳转到订单详情页

**异常测试：**
- 未输入金额：提示"请输入金额"
- 金额为0或负数：提示"请输入金额"
- 接口返回错误：显示错误信息
- 重复点击：按钮防重复点击

---

#### 测试用例 2：查看订单详情

**前置条件：**
- 已有待支付订单

**操作步骤：**
1. 从订单列表或支付成功后进入订单详情页
2. 查看订单信息

**预期结果：**
- 显示订单编号（order_sn）
- 显示店铺名称（mer_name）
- 显示付款金额（pay_price）
- 显示折扣信息（discount）
- 显示订单状态（status_text）
- 显示创建时间（create_time）
- 显示备注信息（mark）

---

#### 测试用例 3：用户资产展示

**前置条件：**
- 用户已登录

**操作步骤：**
1. 进入个人中心页面 `pages/me/me`
2. 查看顶部资产卡片

**预期结果：**
- 显示用户佣金余额（commission）
- 显示用户积分数量（points）
- 显示可用优惠券数量（couponCount）

**异常测试：**
- 未登录：不调用接口
- 接口返回错误：显示默认值 0
