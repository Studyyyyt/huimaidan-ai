# 惠买单小程序商户信息后端不支持字段处理文档

更新时间：2026-06-12

## 1. 概述

本文档记录商户信息接口对接过程中，前端页面中存在但后端接口**不返回**的字段清单及处理方式。

**注意：** 2026-06-12 后端已补齐前端提出的商户展示字段，本文档仅作为历史记录。

## 2. 后端已补齐字段

以下字段后端已全部支持，前端已对接完成：

| 字段名 | 接口字段 | 数据来源 | 状态 |
| --- | --- | --- | --- |
| 联系电话 | `phone` | `eb_merchant.service_phone` | ✅ 已对接 |
| 评分 | `rating`、`rating_detail` | 三项评分计算 | ✅ 已对接 |

## 3. 后端仍不支持的功能清单

以下功能在后端商户信息接口中**不返回**：

### 3.1 敏感信息类

| 功能 | 说明 |
| --- | --- |
| 商户后台联系人 | 不返回联系人信息 |
| 银行卡信息 | 不返回银行卡等敏感信息 |

### 3.2 价格相关类

| 功能 | 说明 |
| --- | --- |
| 商户底价折扣 | 不返回底价信息 |
| 垫资池余额 | 不返回垫资池数据 |
| 平台差价 | 不返回差价数据 |

### 3.3 商品相关类

| 功能 | 说明 |
| --- | --- |
| 商品列表 | 不返回商品数据 |
| SKU信息 | 不返回SKU数据 |
| 购物车 | 不返回购物车字段 |

## 4. 处理原则

1. **不伪造数据**：前端不自行计算或 mock 后端未返回的字段
2. **使用真实数据**：优先使用后端返回的 `display` 字段进行展示
3. **空值处理**：字段为空时隐藏对应模块，不显示占位符
4. **登录引导**：未登录时显示"登录后查看会员优惠"引导文案

## 5. 后续扩展

如后端后续新增以下字段，前端需同步更新：

- 商品、SKU、购物车
- 商户底价、垫资池、平台差价
- 后台联系人、银行卡等敏感信息
