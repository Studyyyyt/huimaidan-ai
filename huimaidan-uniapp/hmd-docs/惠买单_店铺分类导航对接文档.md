# 惠买单 - 店铺分类导航前端对接文档

## 功能概述

实现前端"全部分类 → 一级分类 → 二级分类"的面包屑导航展示，支持点击展开/收起分类树。

---

## 1. 接口方案对比

| 方案 | 接口 | 是否需要开发 | 返回数据量 | 适用场景 |
|------|------|------------|-----------|---------|
| **方案A（推荐）** | `GET /api/store/group/options` | ❌ 已有 | 较大（含diy_temp_id等） | 快速对接，数据完整 |
| **方案B** | `GET /api/store/group/tree` | ✅ 新增 | 精简（仅核心字段） | 需要重启Swoole服务 |

> **推荐方案A**：现有接口已返回完整树形数据，前端无需等待后端重启服务即可对接。

---

## 2. 方案A：使用现有接口（推荐）

## 3. 前端实现方案

### 3.1 API 调用封装

```javascript
// api/store.js
import request from '@/utils/request'

/**
 * 获取店铺分组树形结构
 * 用于分类导航展示：全部分类 -> 一级分类 -> 二级分类
 */
export function getStoreGroupTree() {
  return request.get('store/group/tree')
}
```

### 3.2 组件完整示例

```vue
<!-- components/store-category-nav.vue -->
<template>
  <view class="category-nav">
    <!-- 面包屑导航栏 -->
    <view class="breadcrumb-bar">
      <scroll-view scroll-x class="breadcrumb-scroll">
        <view class="breadcrumb">
          <!-- 全部分类 -->
          <text 
            class="breadcrumb-item" 
            :class="{ active: currentLevel === 0 }"
            @click="selectLevel(0)"
          >
            全部分类
          </text>
          
          <!-- 一级分类 -->
          <template v-if="selectedFirst">
            <text class="breadcrumb-separator">›</text>
            <text 
              class="breadcrumb-item" 
              :class="{ active: currentLevel === 1 }"
              @click="selectLevel(1)"
            >
              {{ selectedFirst.name }}
            </text>
          </template>
          
          <!-- 二级分类 -->
          <template v-if="selectedSecond">
            <text class="breadcrumb-separator">›</text>
            <text class="breadcrumb-item active">
              {{ selectedSecond.name }}
            </text>
          </template>
        </view>
      </scroll-view>
    </view>

    <!-- 分类列表 -->
    <view class="category-list">
      <view 
        v-for="first in categoryList" 
        :key="first.store_group_id"
        class="first-category"
      >
        <!-- 一级分类项 -->
        <view 
          class="category-item first-item"
          :class="{ 
            selected: selectedFirst?.store_group_id === first.store_group_id,
            expanded: expandedFirst === first.store_group_id
          }"
          @click="toggleFirst(first)"
        >
          <text class="item-name">{{ first.name }}</text>
          <view v-if="first.children && first.children.length" class="arrow-wrapper">
            <text class="arrow">{{ expandedFirst === first.store_group_id ? '−' : '+' }}</text>
          </view>
        </view>

        <!-- 二级分类列表（展开时显示） -->
        <view 
          v-if="expandedFirst === first.store_group_id && first.children && first.children.length"
          class="sub-category-list"
        >
          <view 
            v-for="second in first.children" 
            :key="second.store_group_id"
            class="category-item sub-item"
            :class="{ selected: selectedSecond?.store_group_id === second.store_group_id }"
            @click="selectSecond(second)"
          >
            <text class="item-name">{{ second.name }}</text>
          </view>
        </view>
      </view>
    </view>
  </view>
</template>

<script>
import { getStoreGroupTree } from '@/api/store'

export default {
  name: 'StoreCategoryNav',
  
  data() {
    return {
      categoryList: [],       // 完整分类数据
      expandedFirst: null,    // 当前展开的一级分类ID
      selectedFirst: null,    // 选中的一级分类对象
      selectedSecond: null,   // 选中的二级分类对象
      currentLevel: 0         // 当前面包屑层级（0/1/2）
    }
  },
  
  created() {
    this.loadCategories()
  },
  
  methods: {
    /**
     * 加载分类数据
     */
    async loadCategories() {
      try {
        const res = await getStoreGroupTree()
        if (res.status === 200) {
          this.categoryList = res.data
        }
      } catch (e) {
        console.error('加载分类失败', e)
        uni.showToast({ title: '加载分类失败', icon: 'none' })
      }
    },

    /**
     * 切换一级分类展开/收起
     */
    toggleFirst(item) {
      if (this.expandedFirst === item.store_group_id) {
        // 已展开 → 收起
        this.expandedFirst = null
      } else {
        // 展开
        this.expandedFirst = item.store_group_id
      }
      
      this.selectedFirst = item
      this.selectedSecond = null
      this.currentLevel = 1
      
      // 触发筛选
      this.emitChange()
    },

    /**
     * 选择二级分类
     */
    selectSecond(item) {
      this.selectedSecond = item
      this.currentLevel = 2
      
      // 触发筛选
      this.emitChange()
    },

    /**
     * 面包屑层级点击
     */
    selectLevel(level) {
      if (level === 0) {
        // 点击"全部分类" → 重置
        this.selectedFirst = null
        this.selectedSecond = null
        this.expandedFirst = null
        this.currentLevel = 0
      } else if (level === 1) {
        // 点击一级分类 → 回到一级展开状态
        this.selectedSecond = null
        this.currentLevel = 1
      }
      
      // 触发筛选
      this.emitChange()
    },

    /**
     * 触发change事件，通知父组件筛选条件变更
     */
    emitChange() {
      this.$emit('change', {
        firstId: this.selectedFirst?.store_group_id || null,
        secondId: this.selectedSecond?.store_group_id || null,
        first: this.selectedFirst,
        second: this.selectedSecond,
        breadcrumb: this.getBreadcrumbText()
      })
    },

    /**
     * 获取面包屑文本
     */
    getBreadcrumbText() {
      const parts = ['全部分类']
      if (this.selectedFirst) parts.push(this.selectedFirst.name)
      if (this.selectedSecond) parts.push(this.selectedSecond.name)
      return parts.join(' > ')
    }
  }
}
</script>
```

## 4. 使用示例

### 4.1 在店铺列表页使用

```vue
<!-- pages/store/list/index.vue -->
<template>
  <view class="store-page">
    <!-- 分类导航组件 -->
    <store-category-nav @change="onCategoryChange" />
    
    <!-- 店铺列表 -->
    <view class="store-list">
      <view 
        v-for="store in storeList" 
        :key="store.mer_id"
        class="store-item"
        @click="goStoreDetail(store.mer_id)"
      >
        <image :src="store.mer_avatar" class="store-avatar" />
        <view class="store-info">
          <view class="store-name">{{ store.mer_name }}</view>
          <view class="store-desc">{{ store.address }}</view>
        </view>
      </view>
    </view>
  </view>
</template>

<script>
import StoreCategoryNav from '@/components/store-category-nav.vue'
import { getStoreList } from '@/api/store'

export default {
  components: { StoreCategoryNav },
  
  data() {
    return {
      storeList: [],
      filterParams: {
        firstId: null,
        secondId: null
      },
      page: 1,
      loading: false
    }
  },
  
  methods: {
    /**
     * 分类筛选变更
     */
    onCategoryChange({ firstId, secondId }) {
      this.filterParams = { firstId, secondId }
      this.page = 1
      this.storeList = []
      this.loadStoreList()
    },

    /**
     * 加载店铺列表
     */
    async loadStoreList() {
      if (this.loading) return
      this.loading = true
      
      try {
        const res = await getStoreList({
          page: this.page,
          limit: 10,
          // 优先使用二级分类ID，没有则使用一级分类ID
          store_group_id: this.filterParams.secondId || this.filterParams.firstId
        })
        
        if (res.status === 200) {
          this.storeList = [...this.storeList, ...res.data.list]
        }
      } catch (e) {
        console.error('加载店铺失败', e)
      } finally {
        this.loading = false
      }
    },

    goStoreDetail(merId) {
      uni.navigateTo({ url: `/pages/store/detail/index?id=${merId}` })
    }
  },
  
  onReachBottom() {
    this.page++
    this.loadStoreList()
  }
}
</script>
```

## 5. UI/UX 交互规范

### 5.1 状态流转

```
初始状态
├── 面包屑: "全部分类"（高亮）
├── 一级分类平铺展示
└── 无二级分类展开

点击一级分类（如"美食餐饮"）
├── 面包屑: "全部分类 > 美食餐饮"（"美食餐饮"高亮）
├── 该一级分类下方展开二级分类列表
├── 其他一级分类的二级分类收起
└── 触发筛选：firstId=1, secondId=null

点击二级分类（如"鲁菜"）
├── 面包屑: "全部分类 > 美食餐饮 > 鲁菜"（"鲁菜"高亮）
├── 二级分类列表保持展开
└── 触发筛选：firstId=1, secondId=11

点击面包屑"全部分类"
├── 面包屑: "全部分类"（高亮）
├── 所有二级分类收起
└── 触发筛选：firstId=null, secondId=null（加载全部）

点击面包屑"美食餐饮"
├── 面包屑: "全部分类 > 美食餐饮"（"美食餐饮"高亮）
├── 二级分类列表保持展开
└── 触发筛选：firstId=1, secondId=null
```

## 6. 注意事项

### 6.1 数据缓存策略
```javascript
// 建议缓存分类数据，避免重复请求
let cachedCategoryList = null

export async function loadCategoriesWithCache() {
  if (cachedCategoryList) return cachedCategoryList
  
  const res = await getStoreGroupTree()
  if (res.status === 200) {
    cachedCategoryList = res.data
  }
  return cachedCategoryList || []
}
```

### 6.2 空分类处理
- 部分一级分类可能没有二级分类（children为空数组）
- 组件中已处理：无children时隐藏展开箭头

### 6.3 性能优化
- 分类数据变化不频�，建议页面created时加载一次
- 如需全局使用，建议放入Vuex/Pinia状态管理
- 分类数量较多时（>20个一级分类），考虑虚拟列表

### 6.4 坐标定位
- 如需"附近"分类功能，可结合 `GET /api/store/group/recommend` 接口
- 该接口根据经纬度返回距离最近的6个商圈

## 7. 相关接口汇总

| 接口 | 方法 | 说明 | 认证 |
|------|------|------|------|
| `/api/store/group/tree` | GET | 获取分类树（新） | 否 |
| `/api/store/group/options` | GET | 获取级联选项（已有） | 否 |
| `/api/store/group/recommend` | GET | 推荐附近商圈 | 否 |
| `/api/store/merchants` | GET | 店铺列表（支持store_group_id筛选） | 否 |

## 8. 后端重启说明

新增的 `/api/store/group/tree` 接口需要重启 Swoole 服务才能生效：

```bash
# 停止当前服务
kill -9 $(cat runtime/swoole.pid)

# 重新启动服务
php think swoole restart
```

> **注意**：使用现有 `/api/store/group/options` 接口无需重启，可立即对接。
