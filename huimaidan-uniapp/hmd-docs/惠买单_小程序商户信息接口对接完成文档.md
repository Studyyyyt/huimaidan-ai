# 惠买单小程序商户信息接口对接完成文档

更新时间：2026-06-12

## 1. 对接概览

本次对接完成了以下商户信息接口的前端适配：

| 接口 | 状态 | 对接页面 |
| --- | --- | --- |
| `GET /api/huimaidan/store/filters` | 已对接 | 首页筛选栏 |
| `GET /api/huimaidan/store/list` | 已对接 | 首页商户列表 |
| `GET /api/huimaidan/store/categories` | 已对接 | 首页分类标签 |
| `GET /api/huimaidan/store/detail/:id` | 已对接 | 商户详情页 |
| `GET /api/huimaidan/store/nearby` | 接口已定义 | 首页（复用，需定位） |
| `GET /api/huimaidan/store/cities` | 接口已定义 | 待后续页面使用 |

## 2. 变更文件清单

- [huimaidan.ts](src/api/huimaidan.ts)

  - 推荐商品区域改为从商户列表取前3条
  - 商户卡片展示后端返回的真实数据，包括：
    - 分店名（`store_branch_name`）
    - 标语（`slogan`）
    - 销量（`sales_text`）
    - 评分（`rating`）

### 2.3 商户详情页

  - 会员优惠使用 `rules` 数组展示
  - 导航到店使用 `merchant.lat/long` 真实坐标
  - 新增加载状态和错误处理
  - 展示新增字段：

    - 标语（`slogan`）
    - 收录年限（`settled_years_text`）
    - 设施标签（`facility_tags`）
    - 评分（`rating`）
    - 电话（`phone`）
    - 人均消费（`price_per_person_text`）
    - 营业时间（`business_hours`）
    - 促销图（`promo_image`）

### 2.4 位置 Store

- [location.ts](src/store/location.ts)
  - 新增 `latitude`、`longitude` 字段
  - 新增 `setCoordinates()` 方法
  - 新增 `hasCoordinates` 计算属性

## 4. 后端仍不支持的功能清单

以下功能在后端商户信息接口中**不返回**：

- 商户后台联系人信息
- 银行卡等敏感信息
- 商户底价折扣
- 垫资池余额
- 平台差价
- 商品、SKU、购物车字段

## 5. 注意事项

### 5.1 定位权限
- 首页距离筛选需要用户授权获取地理位置
- 未授权时不显示距离筛选选项
- 授权后自动获取经纬度用于距离筛选

### 5.2 登录态兼容
- 商户信息接口不强制登录
- 已登录用户会看到会员优惠标签
- 未登录用户看到"登录后查看会员优惠"提示

### 5.3 缓存处理
- 如果生产环境使用接口缓存，部署后需要清理缓存
- 建议清理应用/路由缓存并重启 Swoole

3. 如后端新增评分、销量等字段，需同步更新前端展示
