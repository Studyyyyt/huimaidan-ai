# 惠买单小程序商户信息接口对接文档

更新时间：2026-06-12

## 1. 对接范围

本文档面向小程序首页商户卡片、商户列表、附近商户、商户详情和筛选栏。

本次后端已补齐前端提出的商户展示字段：公开联系电话、评分、展示销量、分店名、人均消费、营业时间、设施标签、促销图、商户标语和收录年限。所有字段均来自后端真实数据或商户后台配置，不提供 mock 数据。

## 2. 数据来源

| 展示字段 | 接口字段 | 来源 |
| --- | --- | --- |
| 联系电话 | `phone` | `eb_merchant.service_phone` |
| 评分 | `rating`、`rating_detail` | `eb_merchant.product_score/service_score/postage_score` 三项评分 |
| 展示销量 | `sales`、`sales_text` | `eb_huimaidan_merchant_profile.configured_sales + eb_merchant.sales` |
| 真实销量 | `real_sales` | `eb_merchant.sales` |
| 配置销量 | `configured_sales` | 商户后台惠买单展示配置 |
| 分店名 | `store`、`store_branch_name` | 商户后台惠买单展示配置 |
| 收录年限 | `settled_years`、`settled_years_text` | `eb_merchant.create_time` |
| 人均消费 | `price_per_person`、`price_per_person_text` | 商户后台惠买单展示配置 |
| 营业时间 | `business_hours` | 商户后台惠买单展示配置 |
| 设施标签 | `facilities`、`facility_tags` | 商户后台惠买单展示配置 |
| 促销图 | `promo_image` | 商户后台惠买单展示配置 |
| 商户标语 | `slogan` | 商户后台惠买单展示配置 |

`mer_phone` 不会返回给小程序。小程序公开电话只使用 `service_phone`。

## 3. 通用约定

以下路径均带 `/api` 前缀：

```text
https://{domain}/api
```

商户信息接口不强制登录，但会兼容用户 Token：

- 未登录：可浏览商户信息；会员优惠展示可能提示登录后查看。
- 已登录：后端按当前用户会员等级返回可展示优惠。

分页参数沿用 CRMEB 移动端分页：

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `page` | number | 否 | 1 | 页码 |
| `limit` | number | 否 | 项目默认值 | 每页数量 |

## 4. 接口清单

| 页面/功能 | 方法 | 路径 | 登录 |
| --- | --- | --- | --- |
| 商户列表 | GET | `/api/huimaidan/store/list` | 可选 |
| 附近商户 | GET | `/api/huimaidan/store/nearby` | 可选 |
| 商户详情 | GET | `/api/huimaidan/store/detail/:id` | 可选 |
| 商户分类 | GET | `/api/huimaidan/store/categories` | 不强制 |
| 开通城市 | GET | `/api/huimaidan/store/cities` | 不强制 |
| 筛选配置 | GET | `/api/huimaidan/store/filters` | 不强制 |

## 5. 商户列表

```text
GET /api/huimaidan/store/list
```

### 5.1 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 搜索商户名称或商户关键词 |
| `category_id` | number | 否 | 商户分类 ID |
| `city_id` | number | 否 | 城市 ID |
| `order` | string | 否 | `default` 综合排序；`location` 距离最近 |
| `latitude` | number/string | 否 | 用户当前位置纬度，与 `longitude` 必须同时传 |
| `longitude` | number/string | 否 | 用户当前位置经度，与 `latitude` 必须同时传 |
| `distance` | number/string | 否 | 距离筛选，单位 km |
| `page` | number | 否 | 页码 |
| `limit` | number | 否 | 每页数量 |

## 6. 商户详情

```text
GET /api/huimaidan/store/detail/:id
```

`:id` 为商户 ID。

### 6.1 响应结构

```json
{
  "merchant": {},
  "rules": [],
  "display": {}
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `merchant` | object | 商户基础信息，包含详情 Banner、简介、关键词和本次新增展示字段 |
| `rules` | array | 当前用户可展示的会员优惠规则 |
| `display` | object | 适合列表卡片/详情头部直接展示的商户摘要，字段同列表项 |

`merchant` 和 `display` 都会返回本次新增字段。详情页头部建议优先使用 `display`，详情正文可使用 `merchant.mer_banner`、`merchant.mer_info`、`merchant.mer_keyword`、`business_hours`、`facility_tags`、`promo_image`、`slogan`。

## 7. 新增字段说明

| 字段 | 类型 | 空值 | 前端建议 |
| --- | --- | --- | --- |
| `phone` | string | `""` | 为空时隐藏电话按钮 |
| `rating` | number | `0` | 大于 0 时展示 |
| `rating_detail.product_score` | number | `0` | 商品评分 |
| `rating_detail.service_score` | number | `0` | 服务评分 |
| `rating_detail.postage_score` | number | `0` | 物流/履约评分 |
| `real_sales` | number | `0` | 排查来源用，通常不直接展示 |
| `configured_sales` | number | `0` | 排查来源用，通常不直接展示 |
| `sales` | number | `0` | 展示销量数值 |
| `sales_text` | string/null | `null` | 推荐直接展示，如 `半年售35万+` |
| `store` | string | `""` | 兼容前端旧字段，等同分店名 |
| `store_branch_name` | string | `""` | 分店名 |
| `price_per_person` | number | `0` | 人均消费数值 |
| `price_per_person_text` | string/null | `null` | 推荐直接展示 |
| `business_hours` | array | `[]` | 有内容时展示营业时间模块 |
| `facilities.has_large_table` | boolean | `false` | 大桌 |
| `facilities.has_baby_chair` | boolean | `false` | 宝宝椅 |
| `facilities.can_phone_reserve` | boolean | `false` | 电话预订 |
| `facilities.is_non_smoking` | boolean | `false` | 无烟区 |
| `facility_tags` | string[] | `[]` | 推荐直接展示标签 |
| `promo_image` | string | `""` | 为空时隐藏促销图模块 |
| `slogan` | string | `""` | 为空时隐藏标语 |
| `settled_years` | number | `0` | 收录年限数值 |
| `settled_years_text` | string/null | `null` | 推荐直接展示 |

## 8. 定位规则

- 只传 `latitude` 或只传 `longitude`：接口失败，提示 `请同时提供经纬度`。
- 经纬度非数字：接口失败，提示 `经纬度格式错误`。
- 纬度不在 `-90 ~ 90` 或经度不在 `-180 ~ 180`：接口失败，提示 `经纬度超出合法范围`。
- 传 `distance` 时必须同时传经纬度，否则失败，提示 `筛选距离时请提供经纬度`。
- 未传经纬度时，不返回 `distance` 和 `distance_km`，前端不要伪造距离。

## 9. 商户后台维护入口

维护入口：商户后台现有“店铺信息/基础资料”编辑表单。

本次新增可维护字段：

- 分店名
- 配置销量
- 人均消费
- 营业时间
- 大桌
- 宝宝椅
- 电话预订
- 无烟区
- 促销图
- 商户标语

营业时间在商户后台支持一行一条，例如：

```text
周一至周日 10:00-22:00
节假日 10:00-23:00
```

后端会统一转成 `business_hours` 数组返回给小程序。

## 10. 前端调用示例

```ts
export const huimaidanStoreApi = {
  list: (params: {
    keyword?: string
    category_id?: number
    city_id?: number
    order?: 'default' | 'location'
    latitude?: string | number
    longitude?: string | number
    distance?: string | number
    page?: number
    limit?: number
  }) => request.get('/huimaidan/store/list', params),

  nearby: (params: {
    latitude: string | number
    longitude: string | number
    category_id?: number
    city_id?: number
    distance?: string | number
    page?: number
    limit?: number
  }) => request.get('/huimaidan/store/nearby', params),

  detail: (merId: number) =>
    request.get(`/huimaidan/store/detail/${merId}`),

  categories: () =>
    request.get('/huimaidan/store/categories'),

  cities: () =>
    request.get('/huimaidan/store/cities'),

  filters: () =>
    request.get('/huimaidan/store/filters'),
}
```
