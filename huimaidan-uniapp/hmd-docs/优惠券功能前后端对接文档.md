# 惠买单优惠券功能 - 前后端对接文档

> 基于 CRMEB_MER_v3.4 商城系统，本文档覆盖优惠券的完整生命周期：创建、展示、领取、使用。

---

## 一、功能概述

### 1.1 优惠券类型

| 类型值 | 名称 | 说明 |
|--------|------|------|
| `0` | 店铺券 | 指定商户使用的优惠券 |
| `1` | 商品券 | 指定商品可用的优惠券 |
| `10` | 平台通用券 | 平台发放，所有商户可用 |
| `11` | 平台品类券 | 平台发放，指定品类可用 |
| `12` | 平台跨店券 | 平台发放，指定商户可用 |

### 1.2 获取方式 (send_type)

| 值 | 名称 | 说明 |
|----|------|------|
| `0` | 领取 | 用户手动领取 |
| `1` | 消费满赠 | 满足金额自动赠送 |
| `2` | 新人券 | 注册时赠送 |
| `3` | 买赠 | 购买商品后赠送 |
| `4` | 首单赠送 | 首次下单赠送 |
| `5` | 会员券 | SVIP会员专用 |
| `6` | 后台赠送 | 管理员手动发放 |

### 1.3 使用有效期类型 (coupon_type)

| 值 | 说明 |
|----|------|
| `0` | 领取后N天内可用（即时生效） |
| `1` | 指定时间段内可用（固定日期范围） |

### 3.2 领取优惠券（用户端，需登录）

**请求**
```
POST /api/coupon/receive/:id
```

**路由参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| `id` | int | 优惠券ID |

**请求头**
```
Authorization: Bearer {token}
```

**响应示例**
```json
{
    "code": 200,
    "msg": "success",
    "data": "领取成功"
}
```

**失败响应**
```json
{
    "code": 100,
    "msg": "优惠券不存在",
    "data": ""
}
```

```json
{
    "code": 100,
    "msg": "优惠券失效",
    "data": ""
}
```

```json
{
    "code": 100,
    "msg": "优惠券已领取",
    "data": ""
}
```

**后端逻辑** (`StoreCouponRepository::receiveCoupon()`)
1. 检查优惠券是否存在且未删除
2. 验证优惠券有效性（`StoreCouponDao::validCoupon()`）：
   - `status = 1`（状态开启）
   - `is_del = 0`（未删除）
   - `is_limited = 0` 或 `remain_count > 0`（有库存）
   - `is_timeout = 0` 或 当前时间在领取时间范围内
   - `coupon_type = 0` 或 `use_end_time > 当前时间`（使用期未过）
3. 检查是否已领取（`store_coupon_issue_user` 表中是否存在记录）
4. 在事务中执行：
   - 调用 `sendCoupon()` 发送优惠券
   - 调用 `StoreCouponIssueUserRepository::issue()` 创建领取记录
   - 若限量则 `remain_count - 1`
5. 触发事件 `user.coupon.send` 和 `user.coupon.send.receive`

## 六、关键业务规则

### 6.1 优惠券领取限制

1. **单用户单券限制**：每个用户每种优惠券只能领取一次（通过 `store_coupon_issue_user` 表检查）
2. **库存限制**：若 `is_limited=1`，领取时 `remain_count - 1`，为0时不可领取
3. **时间限制**：若 `is_timeout=1`，领取时间需在 `start_time` 到 `end_time` 之间
4. **状态限制**：优惠券 `status=1` 且 `is_del=0`

### 6.2 优惠券使用规则

1. **金额门槛**：订单金额 >= `use_min_price`
2. **商户匹配**：
   - 商户券（type=0）：`mer_id` 必须匹配
   - 平台通用券（type=10）：所有商户可用
   - 平台跨店券（type=12）：商户需在跨店券关联列表中
3. **商品匹配**：商品券（type=1）需在关联商品列表中
4. **品类匹配**：品类券（type=11）需在关联品类下

### 6.3 优惠券过期处理

- 定时任务 `AutoCheckCouponListen` 每30秒检查
- 将超过 `end_time` 的券状态标记为 `status=2`（已过期）

## 七、前端对接要点

### 7.1 未登录处理

```javascript
// 领取优惠券前检查登录状态
if (!this.isLogin) {
    toLogin();  // 跳转登录页
    return;
}
```

### 7.2 领取成功后的交互

```javascript
setCouponReceive(coupon_id).then(res => {
    // 1. 更新本地数据，标记为已领取
    coupon.issue = 1;
    // 2. 显示提示
    showToast({ title: res.message, icon: 'none' });
    // 3. 延迟跳转到可用商品页
    setTimeout(() => {
        navigateTo({
            url: `/pages/columnGoods/goods_coupon_list/index?coupon_id=${coupon_id}`
        });
    }, 500);
}).catch(err => {
    showToast({ title: err, icon: 'none' });
});
```

### 7.3 优惠券状态判断

```javascript
// 判断优惠券是否可领取
const canReceive = (coupon) => {
    // 未过领取时间 或 不限时
    const inReceiveTime = !coupon.is_timeout || 
        (now >= coupon.start_time && now <= coupon.end_time);
    // 有库存 或 不限量
    const hasStock = !coupon.is_limited || coupon.remain_count > 0;
    // 未领取
    const notReceived = !coupon.issue;
    
    return inReceiveTime && hasStock && notReceived;
};

// 判断优惠券是否已过期
const isExpired = (coupon) => {
    return coupon.is_timeout && now > coupon.end_time;
};
```
