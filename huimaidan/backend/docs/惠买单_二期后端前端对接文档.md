# 惠买单二期后端前端对接文档

更新时间：2026-06-01

## 一、说明

二期只交付后端接口，不包含小程序、平台后台和商户后台页面开发。

二期依赖一期数据库变更和接口。部署前必须按顺序执行：

1. `docs/惠买单_一期后端数据库变更.sql`
2. `docs/惠买单_二期后端数据库变更.sql`

所有接口沿用 CRMEB 现有响应结构：成功走 `app('json')->success()`，失败走项目异常或失败响应。禁止前端使用 mock 数据掩盖接口错误。

## 二、二期业务口径

### 2.1 城市归属

- `eb_merchant.city_id` 是惠买单所属城市。
- 城市对应 `eb_city_area.id`，且必须是城市层级 `level=2`。
- 城市由平台后台新增或编辑商户时维护。
- 商户未配置城市时，仍可通过关键词和分类查询，但不会出现在指定城市筛选结果中。

### 2.2 商户列表优惠标签

- 惠买单会员折扣使用 CRMEB 后台“用户等级”能力，不使用付费会员 `is_svip`。
- 未登录用户查看商户列表时，折扣标签展示“登录后查看会员优惠”。
- 登录用户查看商户列表时，折扣标签展示当前用户等级在该商户可享受的消费折扣，例如“会员 8 折”。
- 商户详情只返回当前用户等级可用的公开折扣，不返回商家结算折扣、垫资池和平台差价。
- 用户输入消费金额后，仍以优惠试算接口按当前用户等级计算真实应付金额。

### 2.3 数据真实性

- 未传定位时，商户列表不返回伪造距离。
- 商户没有有效规则时，不伪造优惠标签。
- 平台差价允许为负数，前端不得吞掉或强制归零。
- 预警通知失败时，后端保留失败原因。

### 2.4 资金模式

- 二期当前只实现垫资池模式。新增、编辑或启用优惠规则时，必须绑定当前商户已启用的垫资池。
- 用户端商户列表、商户详情和优惠试算只使用绑定已启用垫资池的规则。
- 垫资池余额允许为负数；只要垫资池仍处于启用状态，用户端试算、下单和支付回调都不会因余额不足而拦截。
- 提现模式后续单独开发；届时提现模式商户不强制绑定垫资池，并使用独立结算链路。
- 二期不新增商户合作模式字段，不在支付回调中静默降级到提现模式。

### 2.5 用户等级会员规则

- 当前业务会员取用户表 `member_level`，等级配置来源于 CRMEB 后台用户等级下的“等级配置、等级管理”。
- 本期不使用 CRMEB 付费会员功能，不读取 `is_svip`、付费会员有效期或付费会员购买记录。
- 只有平台 admin 可以配置商家结算折扣和会员消费折扣。
- admin 必须为所有启用用户等级配置该商户的会员消费折扣；缺少任一等级时不允许保存或启用。
- 惠买单订单支付成功后会进入 CRMEB 现有用户等级成长值和推广等级统计；重复支付回调不会重复累计。

### 2.6 会员商家差异折扣

示例：用户消费 100 元，商家结算折扣为 6 折，当前会员消费折扣为 8 折。

- 用户实付：`100 * 0.80 = 80.00`
- 商家应得：`100 * 0.60 = 60.00`
- 平台差价：`80.00 - 60.00 = 20.00`
- 垫资池扣减：`60.00`

平台差价允许为负数，前端不得吞掉或强制归零。

## 三、用户端 API

用户端公共接口无需 Token。权益摘要接口需要用户 Token。

### 3.1 惠买单商户列表

`GET /api/huimaidan/store/list`

请求参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 商户名称或关键字 |
| `category_id` | int | 否 | 商户分类 ID |
| `city_id` | int | 否 | 惠买单所属城市 ID |
| `order` | string | 否 | 传 `location` 时按距离排序 |
| `latitude` | decimal | 否 | 用户纬度，与 `longitude` 同时传入 |
| `longitude` | decimal | 否 | 用户经度，与 `latitude` 同时传入 |
| `page` | int | 否 | 页码 |
| `limit` | int | 否 | 每页数量 |

仅返回正常营业、未删除且存在当前有效惠买单商家折扣配置、绑定已启用垫资池的商户。

返回字段：

| 字段 | 说明 |
| --- | --- |
| `count` | 符合条件的商户数量 |
| `list[].mer_id` | 商户 ID |
| `list[].mer_name` | 商户名称 |
| `list[].mer_avatar` | 商户头像或 Logo |
| `list[].mer_address` | 商户地址 |
| `list[].category_id` | 商户分类 ID |
| `list[].category_name` | 商户分类名称 |
| `list[].city_id` | 惠买单所属城市 ID |
| `list[].city_name` | 所属城市名称 |
| `list[].longitude` | 经度 |
| `list[].latitude` | 纬度 |
| `list[].business_status` | 营业状态：`1` 营业中、`0` 休息中 |
| `list[].business_status_text` | 营业状态文案 |
| `list[].has_discount` | 是否存在当前有效优惠 |
| `list[].discount_label` | 列表卡片优惠标签 |
| `list[].login_required` | 未登录时返回 `1`，表示需要登录后查看会员优惠 |
| `list[].distance_km` | 真实距离数值，仅传入定位时返回 |
| `list[].distance` | 距离展示文案，仅传入定位时返回 |

### 3.2 附近商户

`GET /api/huimaidan/store/nearby`

请求参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `latitude` | decimal | 是 | 用户纬度 |
| `longitude` | decimal | 是 | 用户经度 |
| `category_id` | int | 否 | 商户分类 ID |
| `city_id` | int | 否 | 城市 ID |
| `page` / `limit` | int | 否 | 分页 |

返回结构与商户列表一致，固定按真实距离升序排列。缺少经纬度时显式返回“请提供经纬度”。

列表和附近商户接口只传一个坐标、传入非数字坐标或超出合法范围时，后端会显式返回参数错误。

### 3.3 商户详情增强

`GET /api/huimaidan/store/detail/:id`

一期接口路径保持不变，二期增加 `display`。

| 字段 | 说明 |
| --- | --- |
| `merchant` | 商户公开信息白名单，不返回联系人、手机号、银行卡等后台敏感字段 |
| `rules` | 当前用户等级可用的公开会员折扣；未登录时为空；不返回商家结算折扣、垫资池和平台差价 |
| `display` | 列表展示结构，标签取第一条有效规则 |

`merchant` 公开字段：`mer_id`、`mer_name`、`mer_avatar`、`mer_banner`、`mer_info`、`mer_keyword`、`mer_address`、`category_id`、`city_id`、`city_name`、`status`、`mer_state`、`long`、`lat`。

### 3.4 商户分类

`GET /api/huimaidan/store/categories`

只返回当前存在有效惠买单规则的商户所使用的真实分类。

| 字段 | 说明 |
| --- | --- |
| `merchant_category_id` | 分类 ID |
| `category_name` | 分类名称 |

### 3.5 可用城市

`GET /api/huimaidan/store/cities`

只返回当前存在有效惠买单规则且已配置城市的商户所使用的真实城市。

| 字段 | 说明 |
| --- | --- |
| `id` | 城市 ID |
| `name` | 城市名称 |
| `code` | 城市编码 |

### 3.6 用户惠买单权益摘要

`GET /api/huimaidan/user/benefit`

登录态：需要用户 Token。

| 字段 | 说明 |
| --- | --- |
| `can_use` | 注册用户是否可使用惠买单，当前固定为 `true` |
| `benefit_text` | 权益说明 |
| `order_count` | 本人已支付惠买单订单数量 |
| `pay_amount` | 本人惠买单实付合计 |
| `saved_amount` | 本人惠买单优惠合计 |

### 3.7 用户等级信息

用户等级相关数据沿用 CRMEB 现有接口，不单独新增 `huimaidan` 前缀接口。

`GET /api/user/member/info`

前端需要展示的核心字段：

| 字段 | 说明 |
| --- | --- |
| `member.brokerage_name` | 当前会员等级名称，普通会员或 VIP |
| `member.brokerage_level` | 当前会员等级值 |
| `member_rate` | 当前等级比例字段，如原接口返回 |
| `next_level` | 下一等级信息和当前生效的开通规则 |
| `upgrade_progress` | 升级进度说明 |

前端展示规则：

- 不使用 mock 数据补齐会员等级。
- 惠买单到店买单支付成功后，前端再次请求以上接口即可获取最新用户等级进度；若队列未消费完成，短时间内可能仍显示旧进度。

## 四、商户后台 API

以下路径沿用商户后台 API 前缀。所有接口由后端绑定当前登录商户 `mer_id`，前端不得传入其他商户 ID。

### 4.1 经营概览

`GET /huimaidan/dashboard/overview`

返回字段：

| 字段 | 说明 |
| --- | --- |
| `pool.pool_id` | 垫资池 ID |
| `pool.balance` | 当前余额 |
| `pool.total_recharge` | 累计充值或调增 |
| `pool.total_consume` | 累计扣减或调减 |
| `pool.alarm_balance` | 预警阈值 |
| `pool.alarm_enabled` | 预警开关 |
| `pool.is_alarm` | 当前是否低余额预警 |
| `active_rule_count` | 当前有效优惠规则数量 |
| `settlement.order_count` | 已支付惠买单订单数量 |
| `settlement.pay_amount` | 用户实付合计 |
| `settlement.merchant_cost_amount` | 商家底价合计 |
| `settlement.platform_profit` | 平台差价合计 |

### 4.2 商户统计

`GET /huimaidan/settlement/stats`

可选参数：`date`、`order_sn`。

返回：`order_count`、`pay_amount`、`merchant_cost_amount`、`platform_profit`。

### 4.3 商户订单列表

`GET /huimaidan/settlement/orders`

可选参数：`paid`、`date`、`order_sn`、`page`、`limit`。

### 4.4 商户订单详情

`GET /huimaidan/settlement/order/:id`

`:id` 为 `store_order.order_id`。查询其他商户订单时返回“订单不存在”。

### 4.5 垫资池流水导出

`GET /huimaidan/pool/transactions/:id/export`

可选参数：`type`、`date`、`page`、`limit`。

返回 CRMEB 既有 Excel 导出结构：`count`、`header`、`title`、`export`、`foot`、`filename`。

## 五、平台后台 API

以下路径沿用平台后台 API 前缀，继续受平台 Token、权限和操作日志中间件保护。

### 5.1 商家会员折扣配置

折扣配置只允许平台 admin 操作。商户后台不提供写接口。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/huimaidan/discount/lst` | 商家折扣配置列表 |
| GET | `/huimaidan/discount/detail/:id` | 商家折扣配置详情 |
| POST | `/huimaidan/discount/create` | 新增商家折扣配置 |
| POST | `/huimaidan/discount/update/:id` | 编辑商家折扣配置 |
| POST | `/huimaidan/discount/status/:id` | 启停商家折扣配置 |
| DELETE | `/huimaidan/discount/delete/:id` | 删除商家折扣配置 |
| GET | `/huimaidan/discount/member_levels` | 可配置用户等级列表 |

`create/update` 核心请求：

```json
{
  "mer_id": 12,
  "pool_id": 5,
  "merchant_discount": "0.60",
  "status": 1,
  "start_time": "2026-06-01 00:00:00",
  "end_time": null,
  "member_discounts": [
    {
      "member_level": 1,
      "member_discount": "0.90",
      "status": 1
    },
    {
      "member_level": 2,
      "member_discount": "0.80",
      "status": 1
    }
  ]
}
```

保存或启用时，`member_discounts` 必须覆盖所有启用用户等级。

### 5.2 垫资池列表增强

`GET /huimaidan/pool/lst`

新增可选参数：

| 字段 | 说明 |
| --- | --- |
| `keyword` | 商户名称、联系人或手机号 |
| `alarm_status` | `1` 当前低余额预警、`0` 当前非预警 |
| `balance_gte` | 最低余额 |
| `balance_lte` | 最高余额 |
| `order_field` | 排序字段：`balance`、`total_consume`、`update_time` |
| `order_direction` | `asc` 或 `desc` |

一期参数 `mer_id`、`status`、`alarm_enabled` 继续可用。

### 5.3 当前预警列表

`GET /huimaidan/pool/alarms`

返回当前 `alarm_enabled=1` 且 `balance <= alarm_balance` 的垫资池。

### 5.4 预警历史

`GET /huimaidan/pool/alarm_records`

可选参数：`pool_id`、`mer_id`、`notice_status`、`date`、`page`、`limit`。

通知状态：

| 值 | 说明 |
| --- | --- |
| `0` | 待通知 |
| `1` | 通知成功 |
| `2` | 通知失败 |

低余额实际触发时，后端同时复用 CRMEB 现有后台消息通道，向在线平台管理员触发实时提示。该提示不提供离线补偿、已读状态或未读数量。二期不新增平台管理员消息中心表；预警历史以 `eb_pool_alarm_record` 持久化记录。

### 5.5 批量设置预警

`POST /huimaidan/pool/batch_alarm`

请求：

```json
{
  "pool_ids": [1, 2, 3],
  "alarm_balance": 500,
  "alarm_enabled": 1
}
```

返回：`updated_count`。

### 5.6 差价收入日趋势

`GET /huimaidan/settlement/daily`

可选参数：`mer_id`、`days`。`days` 默认 `30`，最大 `366`。

每日返回：`day`、`order_count`、`pay_amount`、`merchant_cost_amount`、`platform_profit`。无订单日期返回真实的零值。

### 5.7 月度对比

`GET /huimaidan/settlement/month_compare`

可选参数：`mer_id`。

返回：

| 字段 | 说明 |
| --- | --- |
| `current_month` | 当前月份 |
| `previous_month` | 上月月份 |
| `current_amount` | 当月平台差价 |
| `previous_amount` | 上月平台差价 |
| `change_amount` | 差额 |
| `change_rate` | 环比百分比；上月为 `0` 时返回 `null` |

### 5.8 商户差价排行

`GET /huimaidan/settlement/rank`

可选参数：`mer_id`、`date`、`page`、`limit`。

### 5.9 平台导出

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/huimaidan/settlement/orders/export` | 惠买单订单明细导出 |
| GET | `/huimaidan/settlement/merchants/export` | 惠买单商户汇总导出 |

返回 CRMEB 既有 Excel 导出结构。

## 七、一期接口继续复用

以下一期接口保持不变：

- `POST /api/huimaidan/discount/calculate`
- `POST /api/huimaidan/order/create`
- `POST /api/huimaidan/order/pay/:id`
- `GET /api/huimaidan/order/list`
- `GET /api/huimaidan/order/detail/:id`
- 商户后台垫资池接口；商户后台优惠规则写接口不再使用，折扣由平台 admin 统一配置
- 平台后台垫资池充值、调整、启停和基础统计接口

一期完整字段参见：`docs/惠买单_一期后端前端对接文档.md`。

用户端优惠试算、创建订单、订单列表和订单详情不会返回垫资池 ID、商家底价、平台差价、垫资流水 ID 或内部优惠快照。前端只使用公开优惠结果和订单展示字段。

## 八、部署和联调要求

1. 执行二期 SQL 前备份数据库。
2. 执行 SQL 后，在平台后台为参与惠买单的商户维护 `city_id`，并由 admin 重新配置商家结算折扣和所有启用用户等级的会员消费折扣。
3. 清理路由和配置缓存。
4. 同步新增平台和商户后台路由权限。
5. 重启 Swoole 常驻进程。
6. 低余额预警会写入商户站内信，并通过 CRMEB 现有 Swoole 后台消息通道向在线平台管理员触发实时提示；通知失败会写入 `eb_pool_alarm_record.notice_message`。
7. 本期未开发前端页面，接口联调由后续前端开发阶段执行。
