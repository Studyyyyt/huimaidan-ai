# 惠买单小程序商户端店铺二维码前端对接文档

更新时间：2026-06-17

## 1. 对接范围

本轮后端为每个惠买单商户按 `mer_id` 生成唯一微信小程序码。用户扫码后进入小程序扫码入口页，再跳转到买单页。

本轮包含：

- 商户后台：查看二维码、刷新二维码、下载二维码。
- 平台后台：检索二维码、查看详情、强制刷新、下载二维码。
- 微信小程序：新增扫码入口页 `pages/scan-entry/index`，解析 `scene` 后跳转买单页。

本轮不包含：

- 多门店 `branch_id` 独立二维码。
- 二维码海报装修。
- URL Scheme 或 H5 中转页。

## 2. 后端真实接口前缀

当前项目配置：

| 端 | 配置项 | 真实前缀 |
| --- | --- | --- |
| 商户后台 API | `config('admin.api_merchant_prefix')` | `/mer` |
| 平台后台 API | `config('admin.api_admin_prefix')` | `/sys` |

因此本文接口均使用当前项目真实路径，不使用旧草案里的 `/merchant`、`/admin`。

## 3. 商户后台接口

### 3.1 获取二维码详情

```http
GET /mer/huimaidan/store_qrcode/detail
```

登录态：商户后台登录态。

说明：

- 后端根据当前登录商户的 `mer_id` 查询二维码。
- 如果记录不存在或图片缺失，后端会尝试生成微信小程序码。
- 生成失败会返回明确错误，不返回 mock 图片。

成功响应 `data`：

```json
{
  "id": 7,
  "mer_id": 1001,
  "mer_name": "示例商户",
  "branch_name_snapshot": "万达店",
  "entry_code": "8F2K9Q",
  "scene_value": "m1001.e8F2K9Q",
  "scene_type": "payment_checkout",
  "page_path": "pages/scan-entry/index",
  "status": 1,
  "status_text": "可用",
  "qr_image_url": "https://example.com/uploads/huimaidan/store-qrcode/1001.png",
  "qr_image_path": "/uploads/huimaidan/store-qrcode/1001.png",
  "last_generated_at": "2026-06-17 12:00:00",
  "last_generate_status": 1,
  "last_generate_status_text": "生成成功",
  "last_generate_error": "",
  "generate_version": 2,
  "refresh_count": 1,
  "last_access_at": "",
  "is_using_last_success": 0,
  "updated_at": "2026-06-17 12:00:00"
}
```

前端展示规则：

| 字段 | 用途 |
| --- | --- |
| `qr_image_url` | 二维码预览图和下载源地址。 |
| `scene_value` | 可提供复制按钮，用于联调排查。 |
| `last_generated_at` | 最近成功生成时间。 |
| `last_generate_status` | `1` 成功，`0` 失败。 |
| `last_generate_error` | 失败原因，失败态必须展示。 |
| `is_using_last_success` | `1` 表示本次刷新失败但仍有上一版可用二维码。 |

失败态：

- 接口失败时直接展示后端错误文案。
- 不允许跳过错误展示默认二维码。
- 不允许使用本地假图片或假商户数据兜底。

### 3.2 刷新二维码

```http
POST /mer/huimaidan/store_qrcode/refresh
```

请求体：

```json
{
  "force": 1
}
```

交互规则：

1. 点击前弹确认框：
   `刷新后将重新生成当前店铺的小程序码。线下已打印二维码如需更换，请重新下载最新图片。是否继续？`
2. 成功后使用响应 `data` 局部更新二维码、时间和状态。
3. 失败时保留当前页面数据，并展示后端错误。
4. 商户端 60 秒内重复刷新会返回：
   `刷新过于频繁，请稍后再试`

### 3.3 下载二维码

```http
GET /mer/huimaidan/store_qrcode/download
```

说明：

- 成功时返回图片下载流。
- 如果图片缺失，后端会先尝试补生成。
- 如果补生成失败，接口失败并返回明确错误。

前端处理：

- Web 管理端可直接打开该 URL 或创建隐藏链接下载。
- 小程序端若需要保存图片，应使用 `qr_image_url` 调用微信下载/保存图片能力，不走后台下载流。

## 4. 平台后台接口

### 4.1 二维码列表

```http
GET /sys/huimaidan/store_qrcode/lst
```

查询参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `page` | number | 页码。 |
| `limit` | number | 每页数量。 |
| `mer_id` | number | 商户 ID。 |
| `keyword` | string | 商户名、商户关键字、负责人、手机号、入口码或 scene。 |
| `status` | number | `1` 可用，`0` 禁用。 |
| `last_generate_status` | number | `1` 最近成功，`0` 最近失败。 |

响应：

```json
{
  "count": 1,
  "list": [
    {
      "mer_id": 1001,
      "mer_name": "示例商户",
      "scene_value": "m1001.e8F2K9Q",
      "qr_image_url": "https://example.com/uploads/huimaidan/store-qrcode/1001.png",
      "last_generate_status": 1,
      "last_generate_error": "",
      "last_generated_at": "2026-06-17 12:00:00"
    }
  ]
}
```

### 4.2 二维码详情

```http
GET /sys/huimaidan/store_qrcode/detail/{mer_id}
```

返回字段同商户后台详情。

### 4.3 强制刷新

```http
POST /sys/huimaidan/store_qrcode/refresh/{mer_id}
```

请求体：

```json
{
  "reason": "admin_force_refresh"
}
```

说明：

- 平台强制刷新不受商户端 60 秒刷新限制。
- 刷新失败时后端会记录 `last_generate_error` 并返回明确错误。

### 4.4 下载二维码

```http
GET /sys/huimaidan/store_qrcode/download/{mer_id}
```

成功时返回图片下载流。

## 5. 小程序扫码入口页

新增页面：

```text
pages/scan-entry/index
```

小程序码生成时后端传给微信的参数：

```json
{
  "page": "pages/scan-entry/index",
  "scene": "m1001.e8F2K9Q",
  "check_path": true,
  "env_version": "release",
  "width": 430
}
```

`scene` 格式：

```text
m{mer_id}.e{entry_code}
```

示例：

```text
m1001.e8F2K9Q
```

解析示例：

```ts
function parseStoreQrcodeScene(rawScene: string) {
  const scene = decodeURIComponent(rawScene || '')
  const matched = /^m([1-9]\d*)\.e([A-Za-z0-9]{6,10})$/.exec(scene)
  if (!matched) {
    throw new Error('二维码参数错误')
  }
  return {
    merId: Number(matched[1]),
    entryCode: matched[2]
  }
}

export default {
  onLoad(options) {
    try {
      const parsed = parseStoreQrcodeScene(options.scene)
      uni.redirectTo({
        url: `/pages/payment/checkout?id=${parsed.merId}&source=store_qrcode&entry_code=${parsed.entryCode}`
      })
    } catch (error) {
      uni.showToast({
        title: '二维码参数错误',
        icon: 'none'
      })
    }
  }
}
```

小程序规则：

- 必须读取 `options.scene`。
- 必须 `decodeURIComponent`。
- 解析失败时提示 `二维码参数错误`。
- 禁止静默跳首页。
- 禁止使用本地 mock 商户数据兜底。
- 最终买单页仍调用真实接口 `GET /api/huimaidan/store/detail/:id`。

## 6. 权限和部署

SQL 文件：

| 文件 | 用途 |
| --- | --- |
| `docs/sql/惠买单_商户唯一店铺二维码表.sql` | 新增二维码数据表。 |
| `docs/sql/惠买单_店铺二维码菜单权限.sql` | 新增平台后台和商户后台菜单权限。 |

部署后需要：

1. 执行上述 SQL。
2. 确认小程序已发布 `pages/scan-entry/index`，否则微信 `check_path=true` 会返回页面路径错误。
3. 确认后台已配置 `routine_appId`、`routine_appsecret`。
4. 如使用 Swoole 长驻服务，重启 Swoole。
5. 如后台菜单或路由有缓存，清理权限/路由缓存。

## 7. 常见错误

| 场景 | 前端处理 |
| --- | --- |
| `微信 access_token 获取失败` | 展示错误，提示管理员检查小程序配置。 |
| `微信小程序码生成失败：invalid scene` | 展示错误，联系后端检查 scene 规则。 |
| `小程序页面路径错误` | 展示错误，确认小程序页面已发布且路径不带 `/` 和 query。 |
| `二维码图片保存失败` | 展示错误，检查服务器 `public/uploads` 写入权限。 |
| `刷新过于频繁，请稍后再试` | 禁用刷新按钮倒计时后重试。 |
