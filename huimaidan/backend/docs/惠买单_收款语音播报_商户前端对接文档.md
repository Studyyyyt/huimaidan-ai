# 惠买单 - 收款语音播报 商户前端对接文档

## 1. 接口概述

所有接口均在商户端路由组 `merchant.huimaidan.` 下，前缀为 `/merchant/huimaidan/voice_device/`。

**认证方式**：所有接口需要携带商户端 Token（通过 `MerchantTokenMiddleware` + `MerchantAuthMiddleware` 鉴权）。

**请求格式**：
- GET 请求：参数通过 Query String 传递
- POST 请求：参数通过 JSON Body 传递（`Content-Type: application/json`）

**响应格式**：

```json
{
    "status": 200,
    "msg": "success",
    "data": { ... }
}
```

错误响应：

```json
{
    "status": 10001,
    "msg": "错误信息",
    "data": null
}
```

## 2. 接口列表

### 2.1 设备列表

**请求**：`GET /merchant/huimaidan/voice_device/lst`

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认 1 |
| limit | int | 否 | 每页条数，默认 15 |
| keyword | string | 否 | 搜索关键词（匹配设备名称或SN） |

**响应 data**：

```json
{
    "count": 10,
    "list": [
        {
            "id": 1,
            "mer_id": 100,
            "device_sn": "SN12345678",
            "device_name": "前台播报器",
            "device_type": 1,
            "bind_status": 1,
            "status": 1,
            "last_push_time": 1718534400,
            "total_push_count": 156,
            "remark": "",
            "is_del": 0,
            "create_time": 1718448000,
            "update_time": 1718534400
        }
    ]
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 设备ID |
| device_sn | string | 设备SN序列号 |
| device_name | string | 设备名称 |
| device_type | int | 设备类型：1=三木森语音播报器 |
| bind_status | int | 绑定状态：0=未绑定 1=已绑定 |
| status | int | 启用状态：1=启用 0=禁用 |
| last_push_time | int | 最后播报时间（Unix时间戳） |
| total_push_count | int | 累计播报次数 |

### 2.3 绑定设备（新增）

**请求**：`POST /merchant/huimaidan/voice_device/create`

**请求体**：

```json
{
    "device_sn": "SN12345678",
    "device_name": "前台播报器"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| device_sn | string | 是 | 设备SN序列号，最大64字符 |
| device_name | string | 是 | 设备名称，最大64字符 |

**响应 data**：

```json
{
    "id": 1
}
```

**业务规则**：
- 同一商户下SN不能重复
- 每个商户最多绑定10台设备

**错误码**：
- `该设备SN已绑定` - SN重复
- `最多绑定10台设备` - 超出数量限制

## 4. 前端页面开发指引

### 4.1 页面组件：VoiceDevice.vue

**建议目录**：`src/views/merchant/huimaidan/VoiceDevice.vue`

顶部展示三个统计卡片：
- 今日播报次数（today_count）

#### 4.1.2 设备列表区

- **搜索栏**：关键词输入框（匹配设备名称/SN）
- **操作栏**：「绑定设备」按钮
- **表格列**：

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 设备名称 | device_name | 150 | - |
| 设备SN | device_sn | 150 | - |
| 设备类型 | device_type | 100 | 固定显示"三木森" |
| 绑定状态 | bind_status | 100 | Tag标签：已绑定/未绑定 |
| 启用状态 | status | 100 | Switch开关 |
| 累计播报 | total_push_count | 100 | 数字 |
| 最后播报 | last_push_time | 160 | 格式化为时间字符串 |
| 操作 | - | 200 | 编辑 / 测试播报 / 删除 |

| 列名 | 字段 | 宽度 |

| 播报类型 | push_type | 100 |
| 推送状态 | push_status | 100 |

  - push_type: 1=收款播报 / 2=测试播报

## 5. 业务流程说明

### 5.1 设备绑定流程

1. 商户在前端输入设备SN和名称，点击"绑定设备"
2. 前端调用 `POST /merchant/huimaidan/voice_device/create`
3. 后端校验SN唯一性和数量限制，保存设备记录
4. 设备初始状态为 `启用`，绑定状态为 `未绑定`
5. 首次收款播报时，后端会自动调用三木森 `bindKeyReq` 完成设备绑定

### 5.2 收款播报流程（自动）

1. 用户支付成功 → 支付回调触发 `OrderRepository::paySuccess()`
2. 支付成功后自动调用 `broadcastVoice()` 方法
3. 后端查询该商户所有启用的设备
4. 为每台设备创建一条播报日志（状态=待推送）
5. 通过 ThinkPHP 队列异步投递 `VoicePushJob`
6. 队列消费者执行 `VoicePushRepository::processPush()`
7. 调用三木森 HTTP 接口 `pushMessageByApiKeyReq`
8. 三木森服务器转发消息到设备，设备播报"微信收款XX元"
9. 更新日志状态为成功/失败，更新设备播报统计

### 5.3 测试播报流程（手动）

1. 商户点击某台设备的"测试播报"按钮
2. 前端调用 `POST /merchant/huimaidan/voice_device/testPush`
3. 后端创建测试播报日志并**同步**调用三木森接口
4. 设备播报"测试播报，收款0.01元"
5. 前端根据返回结果提示成功/失败
