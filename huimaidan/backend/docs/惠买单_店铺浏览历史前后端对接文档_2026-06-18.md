# 惠买单店铺浏览历史前后端对接文档

更新时间：2026-06-18

## 1. 功能范围

本功能只记录惠买单小程序用户进入店铺详情页后的店铺浏览历史，不记录首页、店铺列表、买单页、订单页、商品页或其他页面。

实现口径：

- 登录用户访问 `GET /api/huimaidan/store/detail/:id` 且详情查询成功后，后端自动写入店铺浏览历史。
- 未登录用户仍可访问店铺详情，但不写入浏览历史。
- 同一用户重复浏览同一店铺只保留一条记录，更新最后浏览时间并累加浏览次数。
- 每个用户最多保留最近 60 条店铺浏览历史，超过后自动删除最旧记录。
- 写入失败时详情接口直接失败，后端记录错误日志，不静默跳过。
- 已禁用、已删除或未通过惠买单展示资格的商户不会出现在历史列表。

## 2. SQL 脚本

执行文件：

```text
docs/sql/惠买单_店铺浏览历史表.sql
```

核心表：

```text
eb_user_merchant_history
```

回滚：

```sql
DROP TABLE IF EXISTS `eb_user_merchant_history`;
```

不做旧数据迁移。`eb_user_visit` 中的页面路径不能稳定反推出真实商户 ID，迁移会引入不确定数据。

## 4. 自动写入

```text
GET /api/huimaidan/store/detail/:id
```

登录态：可选。

规则：

- 未登录：正常返回店铺详情，不写历史。
- 已登录：详情成功后写入历史。
- 商户不存在、未营业、未通过惠买单详情校验：详情接口失败，不写历史。
- 写入失败：详情接口失败，后端记录“惠买单店铺浏览历史写入失败”日志。

前端无需额外调用写入接口。

## 5. 获取店铺浏览历史

```text
GET /api/huimaidan/user/merchant_history
```

登录态：必须登录。

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | number | 否 | 默认走项目分页默认值。 |
| `limit` | number | 否 | 默认走项目分页默认值。 |
| `latitude` | string/number | 否 | 用户纬度；与 `longitude` 同传时计算距离。 |
| `longitude` | string/number | 否 | 用户经度；与 `latitude` 同传时计算距离。 |

成功响应：

距离字段说明：

- 同时传 `latitude`、`longitude` 且店铺有坐标时，返回 `shop.distance_km` 和 `shop.distance`。

| 未登录 | 复用现有 Token 中间件错误 |

## 6. 删除单条浏览历史

```text
POST /api/huimaidan/user/merchant_history/delete/:id
```

登录态：必须登录。

路径参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | number | 是 | `history_id`。 |

规则：

- 只能删除当前登录用户自己的记录。
- 记录不存在或不属于当前用户，返回 `浏览记录不存在`。

成功响应：

```json
"浏览记录已删除"
```

## 7. 批量删除或清空

```text
POST /api/huimaidan/user/merchant_history/batch_delete
```

登录态：必须登录。

批量删除请求：

```json
{
  "history_ids": [12, 13]
}
```

清空全部请求：

```json
{
  "clear": 1
}
```

规则：

- `history_ids` 和 `clear=1` 必须二选一。
- `history_ids` 任一 ID 不存在或不属于当前用户，接口直接失败，不部分删除。
- `clear=1` 只清空当前登录用户的店铺浏览历史。

错误文案：

| 场景 | 错误 |
| --- | --- |
| 未传删除参数 | `请选择要删除的浏览记录` |
| `clear` 与 `history_ids` 同传 | `清空和批量删除不能同时操作` |
| ID 不存在或越权 | `浏览记录不存在` |

成功响应：

```json
"浏览记录已删除"
```

## 8. 前端 API 封装

```ts
export const shopHistoryApi = {
  list: (params: { page?: number; limit?: number; latitude?: number; longitude?: number }) =>
    request.get('/huimaidan/user/merchant_history', params),
  delete: (historyId: number) =>
    request.post(`/huimaidan/user/merchant_history/delete/${historyId}`),
  batchDelete: (historyIds: number[]) =>
    request.post('/huimaidan/user/merchant_history/batch_delete', { history_ids: historyIds }),
  clear: () =>
    request.post('/huimaidan/user/merchant_history/batch_delete', { clear: 1 }),
}
```

页面建议：

- 店铺详情页继续调用 `request.get('/huimaidan/store/detail/${merId}')`，无需额外写入浏览历史。
- 历史页使用 `item.shop` 渲染店铺卡片。
- 点击卡片跳转到真实店铺详情页，并传 `item.mer_id`。
- 删除时传 `history_id`，不要传 `mer_id`。
- 空列表展示“暂无浏览记录”。
- 接口失败时直接展示后端错误信息，不使用假数据填充。

## 9. 旧接口边界

| 接口 | 用途 |
| --- | --- |
| `GET /api/user/history` | CRMEB 商品/SPU 浏览历史，不用于惠买单店铺历史。 |
| `POST /api/common/visit` | 页面 PV 或页面访问记录，不用于惠买单店铺历史列表。 |
| `GET /api/huimaidan/user/merchant_history` | 惠买单店铺浏览历史，本需求新增。 |
