# 惠买单三期提现模式后端前端对接文档

更新时间：2026-06-05

## 1. 前置说明

- 本期新增商户合作模式：`1=垫资池模式`，`2=提现模式`。
- 提现模式复用商户余额 `merchant.mer_money` 与商户财务申请表 `financial`。
- 提现模式只支持微信收款码和支付宝收款码，不支持银行卡。
- 所有失败会返回明确业务错误，不做静默降级。

## 2. 平台商户配置

现有平台商户新增/编辑接口增加字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `huimaidan_settlement_mode` | int | 是 | `1` 垫资池，`2` 提现 |
| `huimaidan_withdraw_rate` | decimal | 是 | 提现手续费率，范围 `0-100`，如 `2.50` |

校验：

- 合作模式只能是 `1` 或 `2`。
- 手续费率必须在 `0-100` 之间。
- 历史订单不会因商户配置调整而重算，订单创建时会快照 `settlement_mode`。

## 3. 商户端提现接口

所有接口走商户后台前缀，并受商户后台登录、权限、基础信息校验中间件约束。

### 3.1 提现概览

`GET /huimaidan/settlement/overview`

返回字段：

| 字段 | 说明 |
| --- | --- |
| `settlement_mode` | 当前合作模式 |
| `mer_money` | 当前商户余额 |
| `withdraw_rate` | 当前提现手续费率 |
| `account_type` | 当前收款码类型，`2` 微信，`3` 支付宝 |
| `account_type_label` | 收款码类型文案 |
| `has_account` | 是否已配置可用收款码 |
| `has_unfinished_apply` | 是否存在未完成提现申请 |
| `current` | 当前未完成申请，没有则为 `null` |

### 3.2 当前未完成申请

`GET /huimaidan/settlement/withdraw/current`

未完成范围：

- `status=0`
- `status=1 AND financial_status=0`

返回结构：

```json
{
  "current": null
}
```

存在未完成申请时，`current` 为提现申请对象。

### 3.3 提现记录

`GET /huimaidan/settlement/withdraw/records`

支持筛选：

| 参数 | 说明 |
| --- | --- |
| `date` | 时间范围，沿用 CRMEB 格式 |
| `status` | 审核状态 |
| `financial_status` | 打款状态 |
| `account_type` | `2` 微信，`3` 支付宝 |

### 3.4 保存收款码

`POST /huimaidan/settlement/withdraw/account`

微信参数：

```json
{
  "financial_type": 2,
  "name": "张三",
  "wechat": "wechat_id",
  "wechat_code": "/uploads/xxx.png"
}
```

支付宝参数：

```json
{
  "financial_type": 3,
  "name": "张三",
  "alipay": "account@example.com",
  "alipay_code": "/uploads/xxx.png"
}
```

校验：

- `financial_type` 只能是 `2` 或 `3`。
- 微信必须填写姓名、微信号、收款二维码。
- 支付宝必须填写姓名、支付宝账号、收款二维码。

### 3.5 提交提现申请

`POST /huimaidan/settlement/withdraw/apply`

参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `extract_money` | decimal | 是 | 申请提现金额，最低 `500` |
| `financial_type` | int | 否 | 不传时使用商户当前默认收款类型 |
| `mark` | string | 否 | 商户备注 |

返回成功文案：`申请成功`

校验：

- 商户必须是提现模式。
- 必须配置微信或支付宝收款码。
- 金额必须大于等于 `500`。
- 金额不得大于 `mer_money`。
- 当前不得存在未完成提现申请。

## 4. 平台端提现接口

所有接口走平台后台前缀，并受平台后台登录和权限中间件约束。

### 4.1 列表

`GET /huimaidan/withdraw/lst`

支持筛选：

| 参数 | 说明 |
| --- | --- |
| `date` | 时间范围 |
| `status` | 审核状态 |
| `financial_status` | 打款状态 |
| `account_type` | 收款码类型 |
| `mer_id` | 商户 ID |

### 4.2 详情

`GET /huimaidan/withdraw/detail/:id`

仅返回 `business_type=huimaidan` 的提现申请，非惠买单申请会返回不存在。

### 4.3 审核

`POST /huimaidan/withdraw/audit/:id`

参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `status` | int | 是 | `1` 通过，`-1` 拒绝 |
| `refusal` | string | 拒绝时必填 | 拒绝原因 |
| `audit_remark` | string | 否 | 审核备注 |

规则：

- 拒绝时退回完整 `extract_money` 到商户余额。
- 拒绝退回的是申请金额，不是实际打款金额。

### 4.4 完成打款

`POST /huimaidan/withdraw/transfer/:id`

参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `image` | array | 是 | 打款凭证图片数组 |

成功后：

- `financial_status=1`
- 写入 `image`
- 写入操作管理员和更新时间

### 4.5 统计

`GET /huimaidan/withdraw/stats`

支持筛选：`date`、`mer_id`、`account_type`

返回字段：

| 字段 | 说明 |
| --- | --- |
| `pending_audit_amount` | 待审核金额 |
| `pending_transfer_amount` | 已通过待打款金额 |
| `finished_amount` | 已完成提现金额 |
| `finished_fee_amount` | 已完成手续费金额 |
| `wechat_count` | 微信提现笔数 |
| `wechat_amount` | 微信提现金额 |
| `alipay_count` | 支付宝提现笔数 |
| `alipay_amount` | 支付宝提现金额 |
| `total_count` | 提现申请总数 |

## 5. 支付回调口径

- 垫资池模式订单维持原逻辑：扣减垫资池，写池流水，统计差价。
- 提现模式订单不扣垫资池，支付成功后将 `pay_price` 全额计入商户余额。
- 提现模式订单会写 `financial_record.financial_type=huimaidan_order_income`。
- 重复支付回调不会重复入账。

## 6. 部署注意

1. 先执行 `docs/惠买单_三期后端数据库变更.sql`。
2. 同步执行平台和商户端菜单权限 SQL。
3. 如果线上使用常驻 Swoole，需要重启服务。
4. 如果后台菜单有缓存，需要清理权限/菜单缓存后再联调。
