## 一、二级分销功能禁用（四期）

| 项目 | 内容 |
|------|------|
| **变更日期** | 2026-06-08 |
| **变更类型** | 注释隐藏（非删除） |
| **影响范围** | 后端全部分销相关模块 |
| **统一标记** | `// [已禁用二级分销]` |

### 1.1 变更背景

产品要求：分销模块仅保留**一级分销**能力，隐藏全部**二级分销**相关功能，包括：
- 后台「分销配置」页面中的二级分销比例设置
- 前台/后台所有二级佣金计算、发放、退款逻辑
- 二级推广人关系链（`top_uid` / `valid_top`）
- 二级下线统计、列表查询
- 财务记录、对账、导出中的二级分佣数据

> **前端说明**：`distribution_tabs` 页面为动态表单，内容由后端 API 返回。后端已将 `extension_two_rate` 强制为 0，前端表单中二级相关字段将自动显示为 0/不可见。

### 1.4 数据库变更

> ⚠️ 需手动执行以下 SQL，将已有的二级分销比例配置归零：

```sql
-- 将二级分销比例设为 0
UPDATE eb_system_config SET value = '0' WHERE `value` = 'extension_two_rate';
```

> ⚠️ 注意：`eb_system_config` 表中 `value` 字段存储的是 key 名称，实际值在 `type` 或其他字段中。请根据实际表结构调整 SQL。

### 1.5 恢复指南

**全局搜索标记**：在代码中搜索 `// [已禁用二级分销]` 即可定位所有修改点。

**恢复步骤**：
1. 全局搜索 `// [已禁用二级分销]`，逐文件处理
2. 对于「强制返回 0/null」的方法：删除 `return 0;` / `return null;`，取消下方注释代码的注释
3. 对于「注释代码块」：直接取消注释即可
4. 对于「参数移除」：将被注释的参数/字段加回
5. 执行数据库 SQL 恢复 `extension_two_rate` 的原始值
6. 全局搜索 `extension_two_rate` 确认无遗漏

## 附录：标记规范

所有注释隐藏的代码统一使用以下标记格式：

```
// [已禁用<功能名称>] <说明>
```

示例：
```php
// [已禁用二级分销] 原获取二级推广人 $topUser = $user->valid_top; 现强制为null
$topUser = null;
```

全局搜索命令：
```bash
grep -rn "\[已禁用" --include="*.php" app/ crmeb/
```
