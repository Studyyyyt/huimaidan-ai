# 惠买单一期后端前端对接文档

更新时间：2026-06-01

## 说明

本期只交付后端接口，前端暂不改动。所有接口沿用 CRMEB 现有响应结构：成功走 `app('json')->success()`，失败走项目异常/失败响应，不提供 mock 数据。

上线前必须先执行 `docs/惠买单_一期后端数据库变更.sql`，并清理路由/配置缓存；支付监听变更后需要重启 Swoole/队列/常驻进程。

## 用户端 API

### 商户信息

`GET /api/huimaidan/store/detail/:id`

返回字段：

| 字段 | 说明 |
| --- | --- |
| `merchant` | CRMEB 商户信息 |
| `rules` | 当前有效惠买单优惠规则列表 |

### 优惠试算

`POST /api/huimaidan/discount/calculate`

登录态：需要用户 Token

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mer_id` | int | 是 | 商户 ID |
| `amount` | decimal | 是 | 用户输入消费金额 |

返回核心字段：

| 字段 | 说明 |
| --- | --- |
| `original_amount` | 原始消费金额 |
| `rule_id` | 命中的优惠规则 ID |
| `discount_type` | 1折扣、2立减、3积分抵扣 |
| `discount_rule` | 优惠规则名称 |
| `pay_amount` | 用户应付金额，最低 `0.01` |
| `saved_amount` | 优惠金额 |

`pool_id`、商家底价、平台差价、垫资流水 ID 和下单快照属于内部结算字段，不向用户端返回。没有绑定已启用垫资池的有效规则时，接口显式返回错误。

### 创建并支付惠买单订单

`POST /api/huimaidan/order/create`

登录态：需要用户 Token

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mer_id` | int | 是 | 商户 ID |
| `amount` | decimal | 是 | 消费金额 |
| `pay_type` | string | 是 | `balance`、`weixin`、`routine`、`h5`、`alipay`、`alipayQr`、`weixinQr` |
| `mark` | string | 否 | 用户备注 |
| `return_url` | string | 否 | 支付宝返回地址 |

返回：与 CRMEB 原支付接口一致，`status` 为支付方式，数据内包含支付 `config` 和 `order_id`。这里的 `order_id` 是 `store_group_order.group_order_id`。

### 再次支付

`POST /api/huimaidan/order/pay/:id`

`:id` 为 `group_order_id`。

请求字段同支付相关字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `pay_type` 或 `type` | string | 是 | 支付方式 |
| `return_url` | string | 否 | 支付宝返回地址 |

### 订单列表

`GET /api/huimaidan/order/list`

登录态：需要用户 Token

可选查询：

| 字段 | 说明 |
| --- | --- |
| `paid` | 0未支付、1已支付 |
| `date` | 项目既有日期筛选格式 |
| `page` / `limit` | 分页 |

### 订单详情

`GET /api/huimaidan/order/detail/:id`

`:id` 为 `store_order.order_id`。

## 商户后台接口

前缀沿用商户后台 API 前缀。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/huimaidan/pool/info` | 当前商户垫资池信息，不存在则初始化 |
| POST | `/huimaidan/pool/alarm/:id` | 设置预警金额和开关 |
| GET | `/huimaidan/pool/transactions/:id` | 垫资池流水 |
| GET | `/huimaidan/discount/lst` | 优惠规则列表 |
| POST | `/huimaidan/discount/create` | 新增优惠规则 |
| POST | `/huimaidan/discount/update/:id` | 编辑优惠规则 |
| POST | `/huimaidan/discount/status/:id` | 启停优惠规则 |
| DELETE | `/huimaidan/discount/delete/:id` | 删除优惠规则 |

优惠规则字段：

| 字段 | 说明 |
| --- | --- |
| `title` | 规则名称 |
| `rule_type` | 1折扣、2立减、3积分抵扣 |
| `pool_id` | 垫资池 ID；二期当前垫资池模式下必填，且必须属于当前商户并处于启用状态 |
| `platform_discount` | 平台折扣，例如 `0.60` |
| `merchant_cost` | 商家底价折扣，例如 `0.50`，不能高于平台折扣 |
| `coupon_amount` | 立减金额 |
| `point_ratio` | 积分抵扣比例 |
| `min_amount` | 最低消费金额 |
| `status` | 0关闭、1开启 |
| `start_time` / `end_time` | 有效期，可为空 |

## 支付回调

惠买单支付使用 `attach=huimaidan_order`，事件绑定为：

`pay_success_huimaidan_order => crmeb\listens\pay\HuimaidanOrderPaySuccessListen`

支付成功后后端会：

1. 校验回调金额与订单金额一致。
2. 幂等扣减垫资池。
3. 写入 `store_order.pool_transaction_id`。
4. 标记 `store_group_order` 和 `store_order` 已支付。
5. 将惠买单订单直接置为完成状态。

垫资池未绑定或已停用、规则不可用、商户不可用、回调金额不一致都会显式报错；垫资池余额不足不会再拦截支付。
