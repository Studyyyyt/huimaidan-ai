# 订单退款功能需求变更开发文档

## 一、项目背景

### 1.1 当前业务现状

当前系统基于传统电商模式设计，退款功能以**商品粒度**为核心，用户需要选择具体的退款商品和数量，系统根据商品价格、运费、积分、佣金等多个维度计算退款金额。

### 1.2 业务痛点

1. **流程复杂**：用户需要理解商品维度的退款逻辑，操作门槛高
2. **数据冗余**：`store_refund_product` 表存储大量商品级退款明细，实际业务中很少使用
3. **计算逻辑复杂**：涉及部分退款、运费分摊、积分返还等多种场景
4. **与实际业务不符**：当前业务场景中不存在独立的商品概念，订单是一个整体服务包

### 1.3 变更目标

将退款功能从**商品粒度**调整为**订单粒度**，实现：

- 用户直接选择订单进行全额退款
- 简化退款金额计算逻辑
- 降低系统复杂度，提升用户体验

## 三、需求变更内容

### 3.1 业务规则变更

#### 3.1.1 退款类型调整

| 变更项 | 变更前 | 变更后 |
|--------|--------|--------|
| 退款粒度 | 商品粒度（可选择部分商品） | 订单粒度（整单退款） |
| 退款类型 | 1:仅退款 2:退款退货 | 1:仅退款（移除退款退货） |
| 退款数量 | 支持部分数量退款 | 固定为订单全部数量 |
| 退款金额 | 根据商品价格计算 | 订单支付全额 |

#### 3.1.2 退款条件

- 订单状态必须为**已支付**（status = 0 或 status = 9）
- 订单未在退款中状态
- 订单在有效退款期内（15天内）

#### 3.1.3 退款金额规则

```
退款金额 = 订单实付金额 (pay_price)
```

- 移除商品维度的金额计算
- 移除运费分摊逻辑
- 移除积分返还逻辑（或简化为全额返还）
- 移除佣金扣减逻辑（或简化处理）

## 四、技术实现方案

### 4.1 数据库变更

#### 4.1.1 表结构调整

**方案A（推荐）：保持表结构不变，简化逻辑**

- 保留 `store_refund_product` 表结构
- 退款时固定插入一条记录，`refund_num` = 订单总数量
- 保持数据兼容性，便于回滚

**方案B：移除商品关联**

- 废弃 `store_refund_product` 表
- 退款单直接关联订单
- 需要较大改动，风险较高

#### 4.1.2 新增字段（可选）

```sql
-- 退款单表新增字段
ALTER TABLE `eb_store_refund_order`
ADD COLUMN `refund_all` tinyint(1) NOT NULL DEFAULT 1 COMMENT '是否全额退款 0:否 1:是' AFTER `refund_type`;
```

```php
public function refund($id, StoreRefundOrderValidate $validate, StoreOrderRepository $orderRepository)
{
    $data = $this->request->params(['type', 'refund_type', 'refund_price', 'num', 'ids', 'refund_message', 'mark', 'pics']);
    $validate->check($data);
    $ids = explode(',', $data['ids']);
    $type = $data['type'];
    // ... 复杂逻辑
}

// 变更后
public function refund($id, StoreRefundOrderValidate $validate, StoreOrderRepository $orderRepository)
{
    $data = $this->request->params(['order_id', 'refund_message', 'pics']);
    $validate->check($data);

    $uid = $this->request->uid();
    $order = $orderRepository->userOrder($id, $uid);

    // 订单校验
    if (!$order) return app('json')->fail('订单不存在');
    if ($order->status < 0) return app('json')->fail('订单已退款');
    if ($order->status == 10) return app('json')->fail('订单不支持退款');
    if (!$order->refund_status) return app('json')->fail('订单已过退款期限');

    // 调用新的退款方法
    $refund = $this->repository->orderRefund($order, $uid, $data);

    return app('json')->success('提交成功', ['refund_order_id' => $refund->refund_order_id]);
}
```

#### 4.2.3 仓库层变更

**文件**: `app/common/repositories/store/order/StoreRefundOrderRepository.php`

**新增方法**:

```php
/**
 * 订单全额退款
 * @param StoreOrder $order 订单对象
 * @param int $uid 用户ID
 * @param array $data 退款数据
 * @return StoreRefundOrder 退款单
 */
public function orderRefund(StoreOrder $order, int $uid, array $data): StoreRefundOrder
{
    // 1. 校验订单状态
    $this->validateOrderForRefund($order);

    // 2. 获取订单商品列表
    $products = $order->orderProduct;
    if (empty($products)) {
        throw new ValidateException('订单商品不存在');
    }

    // 3. 计算退款金额（全额）
    $refundPrice = $order->pay_price;

    // 4. 构建退款数据
    $refundData = [
        'order_id' => $order->order_id,
        'uid' => $uid,
        'mer_id' => $order->mer_id,
        'refund_order_sn' => $this->generateRefundSn(),
        'refund_type' => 1, // 仅退款
        'refund_num' => $order->total_num,
        'refund_price' => $refundPrice,
        'refund_message' => $data['refund_message'] ?? '',
        'pics' => $data['pics'] ?? [],
        'status' => 0, // 待审核
    ];

    // 5. 事务处理
    return Db::transaction(function () use ($refundData, $products, $order) {
        // 创建退款单
        $refund = $this->dao->create($refundData);

        // 创建退款商品记录（固定为全额）
        $refundProducts = [];
        foreach ($products as $product) {
            $refundProducts[] = [
                'refund_order_id' => $refund->refund_order_id,
                'order_product_id' => $product->order_product_id,
                'refund_num' => $product->product_num,
                'refund_price' => $product->product_price,
                'refund_postage' => $product->postage_price,
                'refund_integral' => $product->integral_total,
                'platform_refund_price' => $product->platform_coupon_price,
            ];
        }
        app()->make(StoreRefundProductRepository::class)->insertAll($refundProducts);

        // 更新订单商品退款状态
        foreach ($products as $product) {
            $product->refund_num = 0;
            $product->is_refund = 3; // 全退
            $product->save();
        }

        // 触发退款后置操作
        $this->applyRefundAfter($refund, $order);

        return $refund;
    });
}

/**
 * 校验订单是否可退款
 */
private function validateOrderForRefund(StoreOrder $order): void
{
    if ($order->status < 0) {
        throw new ValidateException('订单已退款');
    }
    if ($order->status == 10) {
        throw new ValidateException('订单不支持退款');
    }
    if (!$order->refund_status) {
        throw new ValidateException('订单已过退款期限');
    }
    if ($order->paid != 1) {
        throw new ValidateException('订单未支付');
    }
}

/**
 * 生成退款单号
 */
private function generateRefundSn(): string
{
    return app()->make(StoreOrderRepository::class)->getNewOrderId(StoreOrderRepository::TYPE_SN_REFUND);
}
```

#### 4.2.4 商户端退款方法变更

```php
/**
 * 商户发起订单退款
 * @param StoreOrder $order 订单对象
 * @param array $data 退款数据
 * @return StoreRefundOrder 退款单
 */
public function merchantOrderRefund(StoreOrder $order, array $data): StoreRefundOrder
{
    // 复用用户端退款逻辑
    $refund = $this->orderRefund($order, $order->uid, $data);

    // 商户发起自动同意
    $refundAutoApprove = merchantConfig($order['mer_id'], 'refund_auto_approve');
    if (!$refundAutoApprove) {
        $this->agree($refund->refund_order_id, ['status' => 1]);
    }

    return $refund;
}
```
