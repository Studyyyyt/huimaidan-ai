## 一、概述

本文档对比前端 API 需求与后端已有接口的匹配情况，为开发团队提供清晰的对接指引。

### 对接状态说明

| 标记 | 含义 | 说明 |
|------|------|------|
| ✅ | 已有接口 | 后端已实现，路径/参数完全匹配，可直接对接 |
| 🔄 | 可复用接口 | 后端有类似功能，需调整路径/参数后复用 |
| 🔧 | 可扩展接口 | 后端有基础功能，需扩展返回字段或逻辑 |
| ❌ | 需开发接口 | 后端无对应实现，需新建接口 |

## 二、按模块详细分析

### 1. 用户认证模块

| 前端接口 | 方法 | 后端接口 | 状态 | 对接说明 |
|---------|------|---------|------|---------|
| `POST /auth/mp_login_type` | POST | `POST /api/auth/mp_login_type` | ✅ | 登录前查询是否需要强制绑定手机号 |
| `POST /auth` | POST | `POST /api/auth` | ✅ | 小程序统一授权登录，成功 token 位于 `data.result.token` |
| `POST /auth/mp_phone` | POST | `POST /api/auth/mp_phone` | ✅ | 手机号快速验证组件绑定，主协议为 `auth_token + phone_code` |
| `POST /auth/mp` | POST | `POST /api/auth/mp` | 🔄 | 旧版小程序授权登录兼容接口，不作为新主流程 |
| `POST /auth/admin/login` | POST | `POST /api/auth/login` | 🔄 | 路径不同，参数格式需适配 |
| `GET /auth/logout` | GET | `POST /api/logout` | 🔄 | 方法不一致（GET vs POST） |
| `GET /user/getCode` | GET | `GET /api/captcha` | 🔄 | 返回格式需适配 |
| `POST /auth/register` | POST | `POST /api/auth/register` | 🔄 | 参数名需适配（phone vs username） |

## 六、前端适配建议

### 1. 请求封装层

```typescript
// src/utils/request.ts
const request = axios.create({
  baseURL: import.meta.env.VITE_SERVER_BASEURL + '/api',
  timeout: 10000,
})

// 请求拦截器 - 添加 Token
request.interceptors.request.use(config => {
  const token = uni.getStorageSync('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器 - 统一格式
request.interceptors.response.use(response => {
  const res = response.data
  if (res.status !== 200) {
    return Promise.reject(new Error(res.message || 'Error'))
  }
  return res.data
})
```

登录接口补充：

- `/api/auth` 使用二层结构，登录成功 token 在 `res.data.result.token`
- `/api/auth` 需要绑定手机号时返回 `res.data.status === 201`
- `/api/auth/mp_phone` 当前主协议为 `auth_token + phone_code`
- 当前没有 `refreshToken` 接口，token 失效后重新走小程序登录流程

### 2. 参数名转换

```typescript
// 分页参数转换
const formatParams = (params: any) => {
  if (params.pageSize) {
    params.limit = params.pageSize
    delete params.pageSize
  }
  return params
}
```

### 3. 接口路径映射

```typescript
// src/api/index.ts
export const api = {

  bindPhone: (authToken: string, phoneCode: string) => request.post('/auth/mp_phone', { auth_token: authToken, phone_code: phoneCode }),
  logout: () => request.post('/logout'),
  
  // 用户

  updateUserInfo: (data: any) => request.post('/user/change/info', data),
  
  // 商户
```

| 接口 | 建议控制器 | 方法名 |
|------|-----------|--------|
| `GET /orders/statistics` | `huimaidan/Order.php` | `statistics` |
| `GET /pay/result/{orderId}` | `huimaidan/Order.php` | `payResult` |
| `POST /home/aiSearch` | `huimaidan/Store.php` | `aiSearch` |
| `GET /config/filters` | `huimaidan/Store.php` | `filters` |
| `GET /coupons/usable` | `StoreCoupon.php` | `usable` |
| `GET /collections/check/{shopId}` | `UserRelation.php` | `checkCollection` |

### 2. 响应格式统一

建议后端统一返回格式：

```json
{
  "code": 0,
  "msg": "success",
  "data": {}
}
```

### 3. 分页参数统一

建议后端支持两种分页参数：

```
page=1&pageSize=10  (前端)
page=1&limit=10     (后端)
```
